CSS Color, Font ও Text Style — Beginner Guide

Website সুন্দর করার জন্য শুধু HTML জানলেই হয় না। Website-এর লেখা, রং, Font এবং Text Style সুন্দরভাবে সাজাতে CSS ব্যবহার করা হয়।

এই গাইডে আমরা CSS Color, HEX, RGB, HSL, Font Family, Font Size, Font Weight, Text Align, Line Height, Letter Spacing এবং আরও অনেক গুরুত্বপূর্ণ বিষয় শিখব।

💡 Beginner Tip: আগে প্রতিটি CSS property নিজে লিখে browser-এ result দেখুন। এভাবেই CSS সবচেয়ে দ্রুত শেখা যায়।

1. CSS Color কী?

CSS-এর color property ব্যবহার করে কোনো লেখার রং পরিবর্তন করা যায়। 

p {
    color: red;
}

এখানে সব paragraph-এর লেখার রং লাল হবে।

2. CSS Color Name

CSS-এ সরাসরি কিছু predefined color name ব্যবহার করা যায়। 

h1 {
    color: blue;
}

p {
    color: green;
}

যেমন:

  • red
  • blue
  • green
  • black
  • white
  • orange
  • purple

3. HEX Color

Website design-এ HEX color অনেক বেশি ব্যবহার করা হয়। HEX color সাধারণত # চিহ্ন দিয়ে শুরু হয়। 

h1 {
    color: #2563eb;
}

p {
    color: #333333;
}

উদাহরণ হিসেবে #000000 কালো এবং #ffffff সাদা রং বোঝায়।

4. RGB Color

RGB-এর অর্থ হলো Red, Green এবং Blue। 

p {
    color: rgb(255, 0, 0);
}

এখানে 255 Red, 0 Green এবং 0 Blue। ফলে রংটি লাল হবে।

5. RGBA Color

RGBA হলো RGB-এর সাথে Alpha যোগ করা। Alpha দিয়ে transparency বা স্বচ্ছতা নিয়ন্ত্রণ করা যায়। 

div {
    background-color: rgba(0, 0, 0, 0.5);
}

এখানে 0.5 মানে প্রায় 50% transparency।

6. HSL Color

HSL-এর অর্থ Hue, Saturation এবং Lightness। 

h1 {
    color: hsl(220, 80%, 50%);
}

CSS-এর advanced color control-এর জন্য HSL বেশ কার্যকর।

7. Background Color

background-color property দিয়ে কোনো element-এর background-এর রং পরিবর্তন করা যায়। 

body {
    background-color: #f5f7fb;
}

.card {
    background-color: white;
}

8. Font Family

font-family দিয়ে লেখার Font নির্ধারণ করা হয়। 

body {
    font-family: Arial, sans-serif;
}

একটি ভালো Font website-এর readability অনেক বাড়াতে পারে।

9. Font Size

font-size দিয়ে লেখার আকার নির্ধারণ করা হয়। 

h1 {
    font-size: 36px;
}

p {
    font-size: 18px;
}

10. Font Weight

লেখাকে কতটা মোটা বা পাতলা দেখাবে তা font-weight দিয়ে নিয়ন্ত্রণ করা যায়। 

h1 {
    font-weight: 700;
}

p {
    font-weight: 400;
}

সাধারণভাবে 400 normal এবং 700 bold-এর কাছাকাছি।

11. Font Style

font-style দিয়ে italic text তৈরি করা যায়। 

p {
    font-style: italic;
}

12. Text Align

Text কোন দিকে থাকবে তা text-align দিয়ে নির্ধারণ করা যায়। 

h1 {
    text-align: center;
}

p {
    text-align: left;
}

প্রধান value:

  • left
  • center
  • right
  • justify

13. Text Decoration

লেখার নিচে underline বা অন্য decoration দিতে text-decoration ব্যবহার করা হয়। 

a {
    text-decoration: none;
}

.underline {
    text-decoration: underline;
}

14. Text Transform

Text-এর uppercase বা lowercase পরিবর্তনের জন্য text-transform ব্যবহার করা যায়। 

h2 {
    text-transform: uppercase;
}

অন্য value:

  • uppercase
  • lowercase
  • capitalize

15. Line Height

এক লাইনের সাথে পরের লাইনের vertical distance নিয়ন্ত্রণ করতে line-height ব্যবহার করা হয়। 

p {
    line-height: 1.8;
}

বাংলা article-এর ক্ষেত্রে ভালো line-height রাখলে পড়তে অনেক আরাম হয়।

16. Letter Spacing

অক্ষরের মধ্যে দূরত্ব বাড়াতে বা কমাতে letter-spacing ব্যবহার করা হয়। 

h1 {
    letter-spacing: 2px;
}

17. Word Spacing

শব্দগুলোর মধ্যকার দূরত্ব নিয়ন্ত্রণ করতে word-spacing ব্যবহার করা যায়। 

p {
    word-spacing: 5px;
}

18. Text Shadow

Text-এর পিছনে shadow তৈরি করতে text-shadow ব্যবহার করা হয়। 

h1 {
    text-shadow: 2px 2px 4px #999;
}

19. Color + Font + Text Style একসাথে

এবার কয়েকটি property একসাথে ব্যবহার করে একটি সুন্দর heading তৈরি করি। 

.title {
    color: #2563eb;
    font-family: Arial, sans-serif;
    font-size: 32px;
    font-weight: 700;
    text-align: center;
    letter-spacing: 1px;
}

21. Beginner Practice

এখন নিজে একটি ছোট Text Card তৈরি করুন। 

<div class="text-card">
    <h2>Learn Web Development</h2>
    <p>HTML, CSS এবং JavaScript শিখুন।</p>
</div>

তারপর CSS লিখুন:

.text-card {
    background-color: #ffffff;
    color: #222222;
    padding: 20px;
    text-align: center;
    border-radius: 12px;
}

.text-card h2 {
    color: #2563eb;
    font-size: 28px;
}

.text-card p {
    font-size: 17px;
    line-height: 1.8;
}

22. Common CSS Mistakes

  • CSS property-এর শেষে semicolon না দেওয়া
  • color এবং background-color গুলিয়ে ফেলা
  • font-size-এর unit ভুলে যাওয়া
  • font-family সঠিকভাবে লেখা না
  • CSS file HTML-এর সাথে link না করা
  • একই selector-এর CSS ভুল জায়গায় লেখা
💡 Tip: CSS শেখার সময় শুধু code মুখস্থ করবেন না। Property পরিবর্তন করে browser-এ কী পরিবর্তন হচ্ছে তা দেখুন।

23. পরবর্তী ধাপে কী শিখবেন?

Color, Font এবং Text Style শেখার পর CSS-এর আরও গুরুত্বপূর্ণ বিষয় যেমন Box Model, Flexbox, Grid এবং Responsive Design শেখা উচিত।

24. FAQ

CSS-এ color কীভাবে পরিবর্তন করব?

color property ব্যবহার করে। যেমন: color: blue;

HEX color কী?

HEX হলো CSS-এ color নির্ধারণের একটি জনপ্রিয় পদ্ধতি, যেমন #2563eb।

Text-এর size কীভাবে পরিবর্তন করব?

font-size property ব্যবহার করতে হবে।

বাংলা লেখার জন্য line-height কেন গুরুত্বপূর্ণ?

ভালো line-height রাখলে paragraph-এর লাইনগুলোর মধ্যে পর্যাপ্ত জায়গা থাকে এবং লেখা পড়তে সহজ হয়।

25. Conclusion

CSS Color, Font এবং Text Style হলো website design-এর অন্যতম গুরুত্বপূর্ণ অংশ। এগুলো ভালোভাবে বুঝতে পারলে আপনার website-এর text অনেক বেশি পরিষ্কার, সুন্দর এবং professional করা সম্ভব।

নিয়মিত practice করুন এবং প্রতিটি property browser-এ পরীক্ষা করুন। এরপর CSS Box Model এবং Flexbox শেখার দিকে এগিয়ে যান।
