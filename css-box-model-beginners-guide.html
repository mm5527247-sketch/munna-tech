CSS Box Model কী? Content, Padding, Border ও Margin

CSS শেখার সময় Box Model একটি খুবই গুরুত্বপূর্ণ বিষয়। একটি HTML element-এর চারপাশে কতটুকু জায়গা থাকবে, ভিতরের space কত হবে এবং border কোথায় থাকবে—এসব বুঝতে Box Model জানতে হয়।

এই beginner guide-এ আমরা Content, Padding, Border, Margin, Width, Height এবং box-sizing সহজভাবে শিখব।

💡 Beginner Tip: Box Model বুঝতে হলে code লেখার পাশাপাশি browser-এ element-এর জায়গা পরিবর্তন করে দেখুন।

1. CSS Box Model কী?

CSS Box Model হলো একটি HTML element-এর চারপাশের structure। প্রতিটি সাধারণ HTML element-কে একটি box হিসেবে ভাবা যায়।

একটি Box Model-এর প্রধান ৪টি অংশ হলো:

  • Content
  • Padding
  • Border
  • Margin

সহজভাবে মনে রাখুন: 

Margin
  ↓
Border
  ↓
Padding
  ↓
Content

2. Content কী?

Content হলো element-এর মূল অংশ। যেমন একটি paragraph-এর লেখা বা একটি image-এর জায়গা হলো content। 

.box {
    width: 300px;
    height: 150px;
}

এখানে width এবং height মূল content area-এর আকার নির্ধারণ করে।

3. Padding কী?

Content এবং Border-এর মধ্যকার জায়গাকে Padding বলা হয়। 

.box {
    padding: 20px;
}

এর ফলে box-এর content-এর চারপাশে 20px ভিতরের space তৈরি হবে।

চারদিকে আলাদা Padding

.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

Shortcut হিসেবেও লেখা যায়: 

.box {
    padding: 10px 20px 30px 40px;
}

ক্রমটি হলো: Top → Right → Bottom → Left

4. Border কী?

Content ও Padding-এর বাইরে যে line বা boundary থাকে সেটি হলো Border। 

.box {
    border: 2px solid black;
}

Border-এর প্রধান অংশ:

  • Border width
  • Border style
  • Border color

উদাহরণ

.box {
    border-width: 3px;
    border-style: solid;
    border-color: blue;
}

5. Border Radius

Box-এর corner গোল করার জন্য border-radius ব্যবহার করা হয়। 

.box {
    border-radius: 10px;
}

Card এবং button design-এ এটি অনেক বেশি ব্যবহার করা হয়।

6. Margin কী?

একটি element-এর বাইরে অন্য element থেকে যে space থাকে তাকে Margin বলা হয়। 

.box {
    margin: 20px;
}

সহজভাবে:

  • Padding = ভিতরের space
  • Margin = বাইরের space

7. চারদিকে আলাদা Margin

.box {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;
}

Shortcut: 

.box {
    margin: 10px 20px 30px 40px;
}

এখানেও ক্রম: Top → Right → Bottom → Left

8. Margin Auto

কোনো নির্দিষ্ট width-এর box মাঝখানে রাখার জন্য অনেক সময় margin: auto ব্যবহার করা হয়। 

.box {
    width: 500px;
    margin: 0 auto;
}

এতে box-টি horizontalভাবে center হতে পারে।

9. Width ও Height

Element-এর content area-এর width এবং height নির্ধারণ করা যায়। 

.box {
    width: 300px;
    height: 200px;
}

Responsive website তৈরি করার সময় fixed width-এর পাশাপাশি percentage, max-width ইত্যাদিও ব্যবহার করা হয়।

10. Box Model-এর বাস্তব উদাহরণ

Content Area

উপরের box-এ আমরা width, padding, border, margin এবং background ব্যবহার করেছি। 

.box-demo {
    width: 260px;
    padding: 25px;
    border: 5px solid #2563eb;
    margin: 30px auto;
    background: #dbeafe;
}

11. Box-এর মোট Width কীভাবে হিসাব করবেন?

Default CSS Box Model-এ শুধু width দিলেই পুরো box-এর final width সবসময় শুধু সেই width-এর সমান হয় না।

ধরুন: 

width: 300px;
padding: 20px;
border: 5px solid black;

তাহলে horizontal হিসাব হবে: 

Content = 300px

Left + Right Padding
= 20px + 20px

Left + Right Border
= 5px + 5px

Total Width
= 300 + 40 + 10
= 350px
💡 তাই default content-box ব্যবহার করলে padding এবং border মোট size বাড়িয়ে দিতে পারে।

12. box-sizing: border-box

CSS-এর একটি খুব দরকারি property হলো box-sizing। 

.box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

এখানে width-এর মধ্যে padding এবং border হিসাব করা হবে। এটি responsive design-এ অনেক কাজে লাগে।

13. সব Element-এর জন্য Border Box

অনেক developer project-এর শুরুতেই নিচের CSS ব্যবহার করেন: 

* {
    box-sizing: border-box;
}

এতে element-এর width এবং height হিসাব করা সহজ হয়।

14. Padding ও Margin-এর পার্থক্য

Padding Margin
Element-এর ভিতরের space Element-এর বাইরের space
Content ও Border-এর মাঝে Element ও অন্য element-এর মাঝে

15. Box Model দিয়ে Card তৈরি

এখন একটি simple profile card তৈরি করি। 

<div class="card">
    <h2>Munna Tech</h2>
    <p>Learn Web Development</p>
</div>

CSS:

.card {
    width: 300px;
    padding: 25px;
    margin: 30px auto;
    border: 1px solid #ddd;
    border-radius: 15px;
    background: white;
}

16. Common Box Model Mistakes

  • Padding এবং Margin-এর কাজ গুলিয়ে ফেলা
  • Width-এর সাথে padding যোগ হয়ে size বেড়ে যাওয়া
  • box-sizing ব্যবহার না করে layout সমস্যা তৈরি করা
  • অতিরিক্ত fixed width ব্যবহার করা
  • Margin collapse-এর বিষয়টি না জানা
  • Mobile screen-এর জন্য responsive size না রাখা

17. Beginner Practice

নিজে একটি card তৈরি করুন যার:

  • Width = 300px
  • Padding = 20px
  • Border = 2px
  • Border radius = 12px
  • Margin = 30px auto

তারপর card-এর background এবং text color পরিবর্তন করে দেখুন।

18. Quick Revision

Content  → মূল লেখা/ছবি
Padding  → Content-এর ভিতরের space
Border   → Box-এর boundary
Margin   → Box-এর বাইরের space

width    → Content width
height   → Content height

box-sizing: border-box;
→ Padding ও Border-কে declared size-এর মধ্যে রাখে

19. FAQ

CSS Box Model কী?

HTML element-এর Content, Padding, Border এবং Margin-এর structure-কে CSS Box Model বলা হয়।

Padding কী?

Content এবং Border-এর মধ্যকার ভিতরের space হলো Padding।

Margin কী?

একটি element-এর বাইরে থাকা space হলো Margin।

box-sizing: border-box কেন ব্যবহার করা হয়?

Element-এর declared width বা height-এর মধ্যে padding এবং border হিসাব করার জন্য এটি ব্যবহার করা হয়।

Padding এবং Margin-এর মধ্যে পার্থক্য কী?

Padding element-এর ভিতরের space তৈরি করে, আর Margin element-এর বাইরের space তৈরি করে।

20. Conclusion

CSS Box Model বুঝতে পারলে website layout তৈরি করা অনেক সহজ হয়ে যায়। Content, Padding, Border এবং Margin-এর পার্থক্য পরিষ্কারভাবে জানা প্রতিটি beginner web developer-এর জন্য গুরুত্বপূর্ণ।
