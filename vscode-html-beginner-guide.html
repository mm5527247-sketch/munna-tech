VS Code দিয়ে HTML Website তৈরি করার Beginner Guide

আপনি যদি একদম নতুন হয়ে Web Development শেখা শুরু করেন, তাহলে VS Code ব্যবহার করে খুব সহজেই HTML Website তৈরি করতে পারবেন। এই গাইডে আমরা একদম শুরু থেকে HTML file তৈরি করে browser-এ Website দেখার পদ্ধতি শিখব।

VS Code কী?

Visual Studio Code বা VS Code হলো একটি জনপ্রিয় code editor। Web Development-এর সময় HTML, CSS এবং JavaScript code লেখার জন্য এটি ব্যবহার করা হয়।

VS Code কেন ব্যবহার করবেন?

VS Code-এ code লেখা সহজ এবং এতে বিভিন্ন useful feature রয়েছে। যেমন code highlighting, auto-completion এবং বিভিন্ন extension ব্যবহার করার সুবিধা।

Step 1: একটি Project Folder তৈরি করুন

প্রথমে আপনার PC-তে একটি নতুন folder তৈরি করুন। উদাহরণ হিসেবে folder-এর নাম দিতে পারেন: 

my-website

এই folder-এর ভিতরেই আপনার HTML, CSS এবং JavaScript file রাখা যাবে।

Step 2: VS Code-এ Folder Open করুন

VS Code খুলুন। এরপর আপনার তৈরি করা project folder-টি VS Code-এর মধ্যে Open করুন।

Step 3: HTML File তৈরি করুন

এখন project folder-এর ভিতরে একটি নতুন file তৈরি করুন। File-এর নাম দিন: 

index.html

Step 4: প্রথম HTML Code লিখুন

এবার index.html file-এর ভিতরে নিচের code লিখুন: 

<!DOCTYPE html>

<html>

<head>
    <title>My First Website</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>This is my first website.</p>

</body>

</html>

Step 5: File Save করুন

Code লেখার পর keyboard থেকে Ctrl + S চাপুন।

File save হওয়ার পর আপনার HTML page browser-এ দেখা যাবে।

Step 6: Browser-এ Website দেখুন

আপনার project folder-এ গিয়ে index.html file-এ double click করুন। এরপর browser-এ আপনার প্রথম Website খুলবে।

HTML Code বুঝে নিন

h1 tag ব্যবহার করে বড় heading তৈরি করা হয়। 

<h1>Hello World!</h1>

p tag ব্যবহার করে paragraph তৈরি করা হয়। 

<p>This is my first website.</p>

HTML + CSS + JavaScript

Web Development শেখার সময় HTML, CSS এবং JavaScript একসাথে শেখা গুরুত্বপূর্ণ।

HTML দিয়ে Website-এর structure তৈরি করা হয়, CSS দিয়ে design করা হয় এবং JavaScript দিয়ে interactive functionality যোগ করা হয়।

Beginner Practice

এখন নিজে একটি ছোট Website তৈরি করার চেষ্টা করুন। Website-এ আপনার নাম, একটি heading এবং একটি paragraph যোগ করুন। 

<h1>My Name is Munna</h1>

<p>I am learning Web Development.</p>

💡 Beginner Tip

শুধু tutorial দেখবেন না। প্রতিটি code নিজে টাইপ করে browser-এ result দেখুন। ভুল হলে ভয় পাবেন না—ভুল থেকেই programming শেখা সহজ হয়।
