25. Common Mistakes

  • HTML element-এর ID ভুল লেখা
  • Function-এর নাম ভুল লেখা
  • onclick-এর ভিতরে function call ভুল করা
  • JavaScript file HTML-এর সাথে ঠিকভাবে যুক্ত না করা
  • addEventListener-এর event name ভুল লেখা
  • Element তৈরি হওয়ার আগে JavaScript দিয়ে সেটি খোঁজা
  • Input-এর .value ব্যবহার করতে ভুলে যাওয়া
Beginner Tip: Button click শেখার সময় প্রথমে onclick দিয়ে simple example করুন। এরপর addEventListener("click", ...) ভালোভাবে practice করুন।

27. Quick Revision

  • Click Event → user button-এ click করলে ঘটে
  • onclick → click handle করার সহজ উপায়
  • addEventListener() → event handle করার flexible উপায়
  • getElementById() → ID দিয়ে HTML element খুঁজে নেয়
  • innerText → element-এর text পরিবর্তন করতে পারে
  • .value → input-এর value নেওয়ার জন্য ব্যবহৃত হয়

28. Frequently Asked Questions

JavaScript Click Event কী?

User কোনো clickable element-এ click করলে যে event তৈরি হয় সেটিই click event।

onclick কী?

HTML element click হলে JavaScript function চালানোর একটি সহজ উপায় হলো onclick।

addEventListener কেন ব্যবহার করা হয়?

JavaScript থেকে event listener যুক্ত করার জন্য addEventListener() ব্যবহার করা হয়।

Button click করে HTML পরিবর্তন করা যায়?

হ্যাঁ। DOM method যেমন getElementById() এবং innerText ব্যবহার করে HTML content পরিবর্তন করা যায়।
