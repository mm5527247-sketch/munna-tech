HTML TUTORIAL

HTML শেখা শুরু করুন 🚀

Beginnerদের জন্য সহজভাবে HTML শেখার প্রথম ধাপ।

Lesson 1: HTML কী?

HTML-এর পূর্ণরূপ হলো HyperText Markup Language। Website-এর structure তৈরি করতে HTML ব্যবহার করা হয়।

Lesson 2: প্রথম HTML Code

নিচের code দিয়ে আপনার প্রথম HTML page তৈরি করতে পারেন: 

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>This is my first website.</p>

</body>

</html>

Lesson 3: Heading

HTML-এ heading তৈরি করতে h1 থেকে h6 পর্যন্ত ব্যবহার করা হয়। 

<h1>My Website</h1>

<h2>About Me</h2>

<h3>My Skills</h3>

Lesson 4: Paragraph

সাধারণ লেখা বা paragraph তৈরি করতে p tag ব্যবহার করা হয়। 

<p>
আমি Web Development শিখছি।
</p>

🎯 আজকের Practice

নিজের নাম দিয়ে একটি HTML page তৈরি করুন। সেখানে একটি heading এবং একটি paragraph লিখুন। 

<h1>My Name is Munna</h1>

<p>
I am learning Web Development.
</p>

Lesson 2: HTML Links

HTML link ব্যবহার করে একটি webpage থেকে অন্য webpage-এ যাওয়া যায়।

Example:

<a href="https://www.google.com">
    Visit Google
</a>

এখানে <a> হলো link তৈরি করার tag এবং href দিয়ে link-এর address দেওয়া হয়।

Lesson 3: HTML Images

HTML-এর <img> tag ব্যবহার করে webpage-এ ছবি দেখানো যায়।

Example:

<img src="profile.png" alt="Munna Tech Profile">

src দিয়ে ছবির file-এর নাম বা location দেওয়া হয়। alt দিয়ে ছবির description দেওয়া হয়।

Example with width:

<img src="profile.png" alt="Profile" width="200">

Lesson 4: HTML Lists

HTML-এ তথ্যকে সুন্দরভাবে সাজানোর জন্য list ব্যবহার করা হয়।

Unordered List:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ordered List:

<ol>
    <li>HTML শিখুন</li>
    <li>CSS শিখুন</li>
    <li>JavaScript শিখুন</li>
</ol>

<ul> ব্যবহার করলে সাধারণ bullet list হয়, আর <ol> ব্যবহার করলে numbered list হয়।

Lesson 5: HTML Tables

HTML table ব্যবহার করে তথ্যকে row এবং column আকারে দেখানো যায়।

Example:

<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Munna</td>
        <td>20</td>
    </tr>
</table>

<table> দিয়ে table তৈরি করা হয়। <tr> দিয়ে row, <th> দিয়ে heading এবং <td> দিয়ে data cell তৈরি করা হয়।

Lesson 6: HTML Forms

HTML form ব্যবহার করে visitor-এর কাছ থেকে নাম, email, message ইত্যাদি তথ্য নেওয়া যায়।

Example:

<form>

    <label>Name:</label>
    <input type="text" placeholder="Your Name">

    <br><br>

    <label>Email:</label>
    <input type="email" placeholder="Your Email">

    <br><br>

    <button type="submit">Submit</button>

</form>

<form> দিয়ে form তৈরি করা হয়। <input> দিয়ে information নেওয়া হয়। আর <button> দিয়ে submit করা যায়।

Lesson 7: HTML Buttons

HTML-এর button ব্যবহার করে visitor-এর জন্য বিভিন্ন ধরনের clickable button তৈরি করা যায়।

Basic Button:

<button>Click Me</button>

Link Button:

<a href="https://www.google.com">
    <button>Visit Google</button>
</a>

Example:

<button> tag দিয়ে clickable button তৈরি করা হয়। Button-এর ভিতরে লেখা পরিবর্তন করে নিজের প্রয়োজন অনুযায়ী নাম দিতে পারেন।

Lesson 8: HTML Headings & Paragraphs

Webpage-এর title বা heading তৈরি করতে HTML-এর <h1> থেকে <h6> tag ব্যবহার করা হয়।

Headings Example:

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Small Heading</h3>

Paragraph Example:

<p>
    This is my first paragraph.
</p>

<h1> সাধারণত সবচেয়ে গুরুত্বপূর্ণ heading। <h6> তুলনামূলকভাবে সবচেয়ে ছোট heading। আর <p> দিয়ে paragraph লেখা হয়।

Lesson 9: HTML Semantic Tags

Semantic tags webpage-এর বিভিন্ন অংশের অর্থ পরিষ্কারভাবে বোঝাতে সাহায্য করে।

<header>Header Area</header>
<nav>Navigation Menu</nav>
<main>Main Content</main>
<section>Section Content</section>
<article>Article Content</article>
<footer>Footer Area</footer>

Common semantic tags হলো header, nav, main, section, article এবং footer।

Lesson 10: HTML Audio

HTML-এর audio tag ব্যবহার করে webpage-এ audio যোগ করা যায়।

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
</audio>

controls ব্যবহার করলে visitor audio play এবং pause করতে পারে।

Lesson 11: HTML Video

HTML-এর video tag ব্যবহার করে webpage-এ video যোগ করা যায়।

<video width="400" controls>
    <source src="video.mp4" type="video/mp4">
</video>

controls দিলে video-এর play, pause এবং volume controls দেখা যায়।

Lesson 12: HTML Comments

Comment code-এর explanation লেখার জন্য ব্যবহার করা হয়। Browser comment দেখায় না।

<!-- This is a comment -->

Comment ব্যবহার করলে নিজের code পরে বুঝতে সুবিধা হয়।

Lesson 13: HTML Div

<div> tag ব্যবহার করে webpage-এর বিভিন্ন content group করা যায়। 

<div>
    <h2>My Website</h2>
    <p>Welcome to my website.</p>
</div>

CSS ব্যবহার করে একটি div-এর design সহজে পরিবর্তন করা যায়।

Lesson 14: HTML Classes

Class ব্যবহার করে এক বা একাধিক HTML element-এ একই CSS style দেওয়া যায়। 

<p class="text">Hello World</p>

<div class="box">
    My Box
</div>

একই class অনেক element-এর মধ্যে ব্যবহার করা যায়।

Lesson 15: HTML IDs

ID একটি নির্দিষ্ট HTML element-কে আলাদা করে চিহ্নিত করতে ব্যবহার করা হয়। 

<h1 id="title">Munna Tech</h1>

<p id="intro">Welcome to my website.</p>

সাধারণত একটি webpage-এ একই ID একাধিক element-এ ব্যবহার করা উচিত নয়।

Lesson 16: HTML Attributes

Attribute HTML element সম্পর্কে অতিরিক্ত information দেয়। 

<a href="https://www.google.com">Google</a>

<img src="profile.png" alt="Profile">

এখানে href, src এবং alt হলো attribute।

Lesson 17: HTML Input Types

Form-এ বিভিন্ন ধরনের input নেওয়ার জন্য input type ব্যবহার করা হয়।

<input type="text">
<input type="email">
<input type="password">
<input type="number">
<input type="date">
<input type="checkbox">
<input type="radio">

প্রয়োজন অনুযায়ী সঠিক input type ব্যবহার করলে form আরও useful হয়।

Lesson 18: HTML Dropdown

Dropdown menu তৈরি করতে <select> এবং <option> ব্যবহার করা হয়। 

<select>
    <option>HTML</option>
    <option>CSS</option>
    <option>JavaScript</option>
</select>

Visitor এখান থেকে একটি option নির্বাচন করতে পারে।

Lesson 19: HTML Meta Tags

Meta tags webpage সম্পর্কে browser এবং search engine-কে information দিতে সাহায্য করে। 

<meta name="description"
content="Munna Tech Web Development Tutorials">

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

Responsive website এবং SEO-এর জন্য কিছু meta tag গুরুত্বপূর্ণ।

Lesson 20: Complete HTML Page

এখন আমরা HTML-এর basic structure একসাথে দেখব। 

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <header>
        <h1>Munna Tech</h1>
    </header>

    <main>
        <h2>Welcome</h2>
        <p>This is my website.</p>

        <a href="https://www.google.com">
            Visit Google
        </a>
    </main>

    <footer>
        <p>Copyright 2026 Munna Tech</p>
    </footer>

</body>

</html>

🎉 Congratulations! আপনি HTML-এর গুরুত্বপূর্ণ basic concepts শেষ করেছেন। এখন CSS শিখলে আপনার HTML website-কে সুন্দরভাবে design করতে পারবেন।
