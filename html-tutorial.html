HTML TUTORIAL

HTML শেখা শুরু করুন 🚀

Beginnerদের জন্য সহজভাবে HTML শেখার প্রথম ধাপ।

Lesson 1: HTML কী?

HTML-এর পূর্ণরূপ হলো HyperText Markup Language। Website-এর structure তৈরি করতে HTML ব্যবহার করা হয়।

Lesson 2: প্রথম HTML Code

নিচের code দিয়ে আপনার প্রথম HTML page তৈরি করতে পারেন: 

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>This is my first website.</p>

</body>

</html>

Lesson 3: Heading

HTML-এ heading তৈরি করতে h1 থেকে h6 পর্যন্ত ব্যবহার করা হয়। 

<h1>My Website</h1>

<h2>About Me</h2>

<h3>My Skills</h3>

Lesson 4: Paragraph

সাধারণ লেখা বা paragraph তৈরি করতে p tag ব্যবহার করা হয়। 

<p>
আমি Web Development শিখছি।
</p>

🎯 আজকের Practice

নিজের নাম দিয়ে একটি HTML page তৈরি করুন। সেখানে একটি heading এবং একটি paragraph লিখুন। 

<h1>My Name is Munna</h1>

<p>
I am learning Web Development.
</p>

Lesson 2: HTML Links

HTML link ব্যবহার করে একটি webpage থেকে অন্য webpage-এ যাওয়া যায়।

Example:

<a href="https://www.google.com">
    Visit Google
</a>

এখানে <a> হলো link তৈরি করার tag এবং href দিয়ে link-এর address দেওয়া হয়।

Lesson 3: HTML Images

HTML-এর <img> tag ব্যবহার করে webpage-এ ছবি দেখানো যায়।

Example:

<img src="profile.png" alt="Munna Tech Profile">

src দিয়ে ছবির file-এর নাম বা location দেওয়া হয়। alt দিয়ে ছবির description দেওয়া হয়।

Example with width:

<img src="profile.png" alt="Profile" width="200">

Lesson 4: HTML Lists

HTML-এ তথ্যকে সুন্দরভাবে সাজানোর জন্য list ব্যবহার করা হয়।

Unordered List:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ordered List:

<ol>
    <li>HTML শিখুন</li>
    <li>CSS শিখুন</li>
    <li>JavaScript শিখুন</li>
</ol>

<ul> ব্যবহার করলে সাধারণ bullet list হয়, আর <ol> ব্যবহার করলে numbered list হয়।

Lesson 5: HTML Tables

HTML table ব্যবহার করে তথ্যকে row এবং column আকারে দেখানো যায়।

Example:

<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Munna</td>
        <td>20</td>
    </tr>
</table>

<table> দিয়ে table তৈরি করা হয়। <tr> দিয়ে row, <th> দিয়ে heading এবং <td> দিয়ে data cell তৈরি করা হয়।
