PC Slow হলে কী করবেন? সহজ সমাধান

PC ধীর হয়ে গেলে প্রথমে বুঝতে হবে কোন কারণে সমস্যা হচ্ছে। Software, storage, RAM অথবা background process-এর কারণে PC slow হতে পারে।

১. Task Manager দেখুন

Ctrl + Shift + Esc চাপলে Task Manager খুলবে। এখানে CPU, Memory এবং Disk usage দেখতে পারবেন।

২. বেশি CPU ব্যবহার করছে এমন App বন্ধ করুন

Task Manager-এর Processes section থেকে কোন application বেশি resource ব্যবহার করছে তা দেখতে পারেন। প্রয়োজন না থাকলে application বন্ধ করতে পারেন।

৩. RAM Usage পরীক্ষা করুন

Memory usage অনেক বেশি হলে একসাথে কম application চালিয়ে দেখুন। Browser-এর অপ্রয়োজনীয় tabs বন্ধ করাও সাহায্য করতে পারে।

৪. Storage Check করুন

C drive-এ খুব কম জায়গা থাকলে কিছু unnecessary files সরিয়ে জায়গা খালি করুন।

৫. Startup Apps কমান

অনেক application PC চালু হওয়ার সময় automatically start হলে boot time বাড়তে পারে। প্রয়োজন নেই এমন startup apps Disable করুন।

৬. Browser পরিষ্কার রাখুন

অনেক tabs এবং extensions browser-এর performance কমাতে পারে। প্রয়োজন নেই এমন extensions remove করুন।

৭. Malware Scan করুন

সন্দেহজনক software ব্যবহার করলে security সমস্যা হতে পারে। Windows Security দিয়ে scan করুন।

৮. Windows Update করুন

Windows Update থেকে available update থাকলে install করুন।

৯. PC Restart করুন

একটানা অনেক সময় PC চালু থাকলে restart করলে temporary performance issue কমতে পারে।

১০. Hardware Upgrade

যদি PC অনেক পুরোনো হয় এবং software-based solution কাজ না করে, তাহলে RAM বা SSD upgrade-এর প্রয়োজন হতে পারে।

শেষ কথা

PC slow হলে সরাসরি নতুন PC কেনার প্রয়োজন নেই। প্রথমে Task Manager, storage এবং startup apps পরীক্ষা করুন।
