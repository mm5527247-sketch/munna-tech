Windows 11-এর 20টি দরকারি Keyboard Shortcut

Windows 11 PC দ্রুত এবং সহজে ব্যবহার করার জন্য Keyboard Shortcut জানা খুবই কাজে লাগে। অনেক কাজ mouse দিয়ে করার পরিবর্তে কয়েকটি key একসাথে চাপলেই দ্রুত করা যায়।

এই article-এ Windows 11-এর 20টি useful keyboard shortcut সহজ বাংলায় দেখানো হয়েছে। Beginner থেকে regular PC user— সবাই এগুলো practice করতে পারেন।

Keyboard Shortcut কী?

Keyboard Shortcut হলো keyboard-এর এক বা একাধিক key একসাথে ব্যবহার করে দ্রুত কোনো কাজ করার পদ্ধতি।

উদাহরণ হিসেবে Ctrl + C ব্যবহার করে selected text বা file copy করা যায় এবং Ctrl + V ব্যবহার করে paste করা যায়।

Beginner Tip: Shortcut শেখার সময় একসাথে সবগুলো মুখস্থ করার দরকার নেই। প্রতিদিন ৩–৪টি shortcut ব্যবহার করার চেষ্টা করুন।

Windows 11-এর 20টি দরকারি Keyboard Shortcut

Ctrl + C

1. Copy

Selected text, file বা অন্য কোনো item copy করার জন্য Ctrl + C ব্যবহার করা যায়।

Ctrl + V

2. Paste

Copy অথবা Cut করা content paste করার জন্য Ctrl + V ব্যবহার করুন।

Ctrl + X

3. Cut

Selected text বা file এক জায়গা থেকে অন্য জায়গায় নেওয়ার জন্য Ctrl + X ব্যবহার করা যায়।

Ctrl + Z

4. Undo

সর্বশেষ করা কোনো কাজ undo করার জন্য Ctrl + Z ব্যবহার করা যায়।

Ctrl + Y

5. Redo

Undo করা কোনো action আবার ফিরিয়ে আনতে Ctrl + Y ব্যবহার করা যায়।

Ctrl + A

6. Select All

কোনো document বা supported area-এর সব content select করতে Ctrl + A ব্যবহার করা যায়।

Ctrl + S

7. Save

Document বা code file save করার জন্য Ctrl + S একটি খুব গুরুত্বপূর্ণ shortcut।

Web Development করার সময় এটি বারবার ব্যবহার করার অভ্যাস করুন।

Ctrl + F

8. Find/Search

কোনো document বা webpage-এ নির্দিষ্ট text খুঁজতে Ctrl + F ব্যবহার করা যায়।

Win + E

9. File Explorer

Windows File Explorer দ্রুত open করার জন্য Windows + E ব্যবহার করতে পারেন।

Win + I

10. Windows Settings

Windows Settings দ্রুত open করতে Windows + I ব্যবহার করা যায়।

Win + L

11. Lock PC

PC দ্রুত lock করার জন্য Windows + L ব্যবহার করা যায়।

Public place বা shared environment-এ PC থেকে উঠে যাওয়ার সময় এটি খুব কাজে লাগে।

Win + S

12. Windows Search

Windows Search দ্রুত open করার জন্য Windows + S ব্যবহার করা যায়।

Win + Shift + S

13. Screenshot

Screen-এর নির্দিষ্ট অংশ capture করার জন্য Windows + Shift + S ব্যবহার করা যায়।

Screenshot নেওয়ার সময় screen-এর প্রয়োজনীয় অংশ select করা যায়।

Alt + Tab

14. Switch Between Apps

Open থাকা application বা window-এর মধ্যে দ্রুত switch করতে Alt + Tab ব্যবহার করুন।

Win + D

15. Show Desktop

Open থাকা windows সরিয়ে desktop দ্রুত দেখতে Windows + D ব্যবহার করা যায়।

Win + V

16. Clipboard History

Windows Clipboard History ব্যবহার করার জন্য Windows + V shortcut কাজে লাগে।

প্রথমবার ব্যবহার করার সময় Clipboard History enable করার option দেখা যেতে পারে।

Win + R

17. Run Dialog

Windows-এর Run dialog দ্রুত open করতে Windows + R ব্যবহার করা যায়।

উদাহরণ হিসেবে Run box-এ বিভিন্ন Windows command বা program চালু করার জন্য প্রয়োজনীয় command লেখা যায়।

Ctrl + Shift + Esc

18. Task Manager

Windows Task Manager দ্রুত open করার জন্য Ctrl + Shift + Esc ব্যবহার করা যায়।

কোনো application সমস্যা করলে বা running processes দেখার প্রয়োজন হলে Task Manager কাজে লাগে।

Win + Left / Right Arrow

19. Window Snap

Active window screen-এর বাম বা ডান দিকে snap করার জন্য Windows + Left Arrow অথবা Windows + Right Arrow ব্যবহার করা যায়।

Win + Ctrl + D

20. New Virtual Desktop

নতুন virtual desktop তৈরি করার জন্য Windows + Ctrl + D ব্যবহার করা যায়।

একাধিক কাজ আলাদা desktop-এ organize করতে এটি কাজে লাগতে পারে।

Ctrl + C, Ctrl + V, Ctrl + X এবং Ctrl + S practice করুন।

Day 2

Ctrl + Z, Ctrl + Y, Ctrl + A এবং Ctrl + F practice করুন।

Day 3

Win + E, Win + I, Win + L এবং Win + S practice করুন।

Day 4

Win + Shift + S, Alt + Tab, Win + D এবং Win + V practice করুন।

Day 5

Win + R, Ctrl + Shift + Esc এবং Window Snap shortcuts practice করুন।

Keyboard Shortcut ব্যবহার করার সুবিধা

  • Mouse-এর ওপর নির্ভরতা কমে
  • অনেক কাজ দ্রুত করা যায়
  • Code editing সহজ হয়
  • File management দ্রুত করা যায়
  • Multitasking সহজ হয়
  • Daily PC workflow আরও efficient হতে পারে
মনে রাখবেন: সব shortcut সব application-এ একইভাবে কাজ নাও করতে পারে। কোনো shortcut ব্যবহার করার আগে আপনি যে application বা Windows feature ব্যবহার করছেন তার behaviour লক্ষ্য করুন।

Common Beginner Mistakes

  • Ctrl এবং Windows key গুলিয়ে ফেলা
  • Shortcut-এর key sequence ভুল করা
  • একসাথে অনেক shortcut মুখস্থ করার চেষ্টা করা
  • Shortcut কাজ না করলে application-এর context না দেখা
  • Keyboard layout বা system settings-এর বিষয়টি না দেখা

Quick Revision

  • Ctrl + C → Copy
  • Ctrl + V → Paste
  • Ctrl + X → Cut
  • Ctrl + Z → Undo
  • Ctrl + Y → Redo
  • Ctrl + S → Save
  • Ctrl + F → Find
  • Win + E → File Explorer
  • Win + I → Settings
  • Win + L → Lock PC
  • Win + Shift + S → Screenshot
  • Alt + Tab → Switch Apps
  • Ctrl + Shift + Esc → Task Manager

Frequently Asked Questions

Windows 11-এ সবচেয়ে basic shortcut কোনগুলো?

Ctrl + C, Ctrl + V, Ctrl + X, Ctrl + Z, Ctrl + S এবং Ctrl + A হলো খুব পরিচিত basic shortcut।

Screenshot নেওয়ার shortcut কোনটি?

Windows 11-এ screen-এর নির্দিষ্ট অংশ capture করার জন্য Windows + Shift + S ব্যবহার করা যায়।

Task Manager দ্রুত কীভাবে খুলব?

Ctrl + Shift + Esc shortcut ব্যবহার করে Task Manager দ্রুত open করা যায়।

File Explorer দ্রুত কীভাবে খুলব?

Windows + E চাপলে File Explorer open করা যায়।

PC দ্রুত Lock করার shortcut কী?

Windows + L ব্যবহার করে PC lock করা যায়।

উপসংহার

Windows 11-এর keyboard shortcut জানা থাকলে daily PC কাজ আরও দ্রুত ও সহজভাবে করা সম্ভব।

Beginner হিসেবে প্রথমে Copy, Paste, Save, Undo, Search, File Explorer, Screenshot এবং Lock-এর মতো shortcut practice করুন। এরপর ধীরে ধীরে আরও advanced shortcut ব্যবহার করার অভ্যাস করুন।
