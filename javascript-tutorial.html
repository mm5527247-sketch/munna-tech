JAVASCRIPT TUTORIAL

JavaScript শেখা শুরু করুন ⚡

Beginnerদের জন্য সহজভাবে JavaScript শেখার সম্পূর্ণ গাইড।

Lesson 1: JavaScript কী?

JavaScript হলো একটি programming language। এটি website-কে interactive এবং dynamic করতে ব্যবহার করা হয়। 

JavaScript = Website-এর আচরণ নিয়ন্ত্রণ করা

Lesson 2: প্রথম JavaScript Code

console.log() ব্যবহার করে browser console-এ message দেখানো যায়। 

console.log("Hello Munna Tech!");

Lesson 3: Button Click

JavaScript দিয়ে button click করলে কোনো action করানো যায়। 

<button onclick="showMessage()">
    Click Me
</button>

<script>

function showMessage() {
    alert("Hello Munna Tech!");
}

</script>

Lesson 4: Variable

কোনো তথ্য সংরক্ষণ করার জন্য variable ব্যবহার করা হয়। 

let name = "Munna";

console.log(name);

Lesson 5: Simple Calculation

JavaScript দিয়ে mathematical calculation করা যায়। 

let a = 10;
let b = 5;

let result = a + b;

console.log(result);

Lesson 6: Data Types

JavaScript-এ বিভিন্ন ধরনের data রাখা যায়। যেমন String, Number এবং Boolean। 

let name = "Munna";
let age = 20;
let student = true;

console.log(name);
console.log(age);
console.log(student);

Lesson 7: if Statement

কোনো condition সত্য হলে নির্দিষ্ট code চালানোর জন্য if ব্যবহার করা হয়। 

let age = 20;

if (age >= 18) {
    console.log("You are an adult");
}

Lesson 8: if...else

Condition সত্য বা মিথ্যা অনুযায়ী দুই ধরনের কাজ করাতে if...else ব্যবহার করা হয়। 

let age = 16;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Not Adult");
}

Lesson 9: Function

একই কাজ বারবার করার প্রয়োজন হলে function তৈরি করা যায়। 

function sayHello() {
    console.log("Hello Munna!");
}

sayHello();

Lesson 10: Function Parameter

Function-এর মধ্যে data পাঠানোর জন্য parameter ব্যবহার করা হয়। 

function greet(name) {
    console.log("Hello " + name);
}

greet("Munna");

Lesson 11: Array

একাধিক value একসাথে রাখার জন্য Array ব্যবহার করা হয়। 

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits);

Lesson 12: Array থেকে Data নেওয়া

Array-এর নির্দিষ্ট item নিতে index ব্যবহার করা হয়। Index 0 থেকে শুরু হয়। 

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]);
console.log(fruits[1]);

Lesson 13: for Loop

একই কাজ বারবার করার জন্য loop ব্যবহার করা হয়। 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Lesson 14: Object

একজন ব্যক্তি বা কোনো বিষয় সম্পর্কিত একাধিক information রাখার জন্য Object ব্যবহার করা যায়। 

let user = {
    name: "Munna",
    age: 20,
    city: "Dhaka"
};

console.log(user.name);
console.log(user.age);

Lesson 15: DOM কী?

DOM-এর মাধ্যমে JavaScript দিয়ে HTML element পরিবর্তন করা যায়। 

<h1 id="title">Hello</h1>

<script>

document.getElementById("title").innerText = "Munna Tech";

</script>

Lesson 16: HTML Element Change

JavaScript দিয়ে HTML element-এর text পরিবর্তন করা যায়। 

<p id="message">Old Text</p>

<script>

document.getElementById("message").innerText =
    "New Text";

</script>

Lesson 17: CSS Change

JavaScript দিয়ে HTML element-এর CSS style পরিবর্তন করা যায়। 

<h1 id="title">Munna Tech</h1>

<script>

document.getElementById("title").style.color = "blue";

</script>

Lesson 18: Event Listener

addEventListener() ব্যবহার করে কোনো event-এর পরে JavaScript code চালানো যায়। 

<button id="btn">
    Click Me
</button>

<script>

document.getElementById("btn")
.addEventListener("click", function() {

    alert("Button Clicked!");

});

Lesson 19: Input থেকে Data নেওয়া

User-এর input নেওয়া এবং JavaScript দিয়ে সেটি ব্যবহার করা যায়। 

<input id="name" placeholder="Your Name">

<button onclick="showName()">
    Submit
</button>

<script>

function showName() {

    let name =
        document.getElementById("name").value;

    alert("Hello " + name);

}

</script>

Lesson 20: Complete JavaScript Example 🚀

এবার HTML এবং JavaScript একসাথে ব্যবহার করে একটি ছোট project তৈরি করি। 

<h2 id="title">My Website</h2>

<button onclick="changeText()">
    Change Text
</button>

<script>

function changeText() {

    document.getElementById("title").innerText =
        "Welcome to Munna Tech!";

}

</script>

🎯 Final Practice

নিজে একটি ছোট JavaScript project তৈরি করুন।

Project-এ একটি input box এবং একটি button থাকবে। User নিজের নাম লিখবে এবং button click করলে তার নাম screen-এ দেখাবে। 

<input id="name" placeholder="Enter your name">

<button onclick="showName()">
    Show Name
</button>

<p id="result"></p>

<script>

function showName() {

    let name =
        document.getElementById("name").value;

    document.getElementById("result").innerText =
        "Hello " + name + "!";

}

</script>
