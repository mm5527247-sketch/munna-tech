JAVASCRIPT TUTORIAL

JavaScript শেখা শুরু করুন ⚡

Beginnerদের জন্য সহজভাবে JavaScript শেখার প্রথম ধাপ।

Lesson 1: JavaScript কী?

JavaScript হলো একটি programming language। এটি website-কে interactive এবং dynamic করতে ব্যবহার করা হয়।

Lesson 2: প্রথম JavaScript Code

নিচের code দিয়ে JavaScript-এর একটি simple message দেখানো যায়: 

console.log("Hello Munna Tech!");

Lesson 3: Button Click

JavaScript দিয়ে button click করলে কোনো কাজ করানো যায়। 

<button onclick="showMessage()">
    Click Me
</button>

<script>

function showMessage() {
    alert("Hello Munna Tech!");
}

</script>

Lesson 4: Variable

কোনো তথ্য সংরক্ষণ করার জন্য JavaScript-এ variable ব্যবহার করা হয়। 

let name = "Munna";

console.log(name);

Lesson 5: Simple Calculation

JavaScript দিয়ে সহজ mathematical calculation করা যায়। 

let a = 10;
let b = 5;

let result = a + b;

console.log(result);

🎯 আজকের Practice

একটি button তৈরি করুন। Button-এ click করলে আপনার নাম দেখাবে। 

<button onclick="showName()">
    Click Me
</button>

<script>

function showName() {
    alert("My name is Munna");
}

</script>
