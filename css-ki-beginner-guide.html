CSS কী? Beginnerদের জন্য CSS সম্পূর্ণ গাইড

একটি Website-এর HTML structure তৈরি করার পর সেটিকে সুন্দর, Professional এবং User-friendly করার জন্য CSS ব্যবহার করা হয়।

এই Beginner Guide-এ আমরা একদম শুরু থেকে CSS কী, কেন ব্যবহার করা হয় এবং কীভাবে HTML-এর সাথে CSS ব্যবহার করতে হয় তা শিখব।

1. CSS কী?

CSS এর পূর্ণরূপ হলো Cascading Style Sheets।

CSS ব্যবহার করে Website-এর Color, Font, Size, Spacing, Layout, Button, Background এবং অন্যান্য Design পরিবর্তন করা যায়।

সহজভাবে মনে রাখুন:
HTML = Website-এর Structure
CSS = Website-এর Design
JavaScript = Website-এর Interaction

2. CSS কেন ব্যবহার করা হয়?

শুধু HTML ব্যবহার করলে Website সাধারণ ও কম আকর্ষণীয় দেখাতে পারে। CSS ব্যবহার করলে Website-এর Design অনেক সুন্দর করা যায়।

  • Text-এর Color পরিবর্তন
  • Font পরিবর্তন
  • Background তৈরি
  • Button Design
  • Margin ও Padding
  • Border তৈরি
  • Website Layout তৈরি
  • Mobile Responsive Design
  • Animation এবং Transition

3. CSS Syntax কী?

CSS-এর সাধারণ Syntax হলো:

selector {
  property: value;
}

উদাহরণ:

p {
  color: blue;
}

এখানে p হলো selector, color হলো property এবং blue হলো value।

4. CSS যোগ করার ৩টি পদ্ধতি

HTML-এর সাথে CSS তিনভাবে ব্যবহার করা যায়:

  1. Inline CSS
  2. Internal CSS
  3. External CSS

5. Inline CSS

HTML Tag-এর ভিতরে সরাসরি CSS লিখলে তাকে Inline CSS বলা হয়।

<h1 style="color: blue;">Hello World</h1>

ছোট কোনো পরিবর্তনের জন্য Inline CSS ব্যবহার করা যায়।

6. Internal CSS

HTML-এর <head> অংশের মধ্যে <style> Tag ব্যবহার করে CSS লিখলে সেটিকে Internal CSS বলা হয়।

<style>
h1 {
  color: red;
}
</style>

7. External CSS

আলাদা একটি CSS File তৈরি করে HTML-এর সাথে যুক্ত করলে তাকে External CSS বলা হয়।

<link rel="stylesheet" href="style.css">

বড় Website-এর জন্য External CSS খুবই জনপ্রিয়, কারণ এতে HTML এবং CSS আলাদা রাখা যায়।

8. CSS দিয়ে Text Color পরিবর্তন

h1 {
  color: blue;
}

এখানে h1-এর Text-এর Color Blue হবে।

9. Background Color

body {
  background-color: lightgray;
}

এতে পুরো Website-এর Background Color পরিবর্তন হবে।

10. Font Size

p {
  font-size: 18px;
}

এখানে Paragraph-এর Font Size 18px হবে।

11. Font Family

body {
  font-family: Arial, sans-serif;
}

Font Family ব্যবহার করে Website-এর Text-এর Font পরিবর্তন করা যায়।

12. Text Align

h1 {
  text-align: center;
}

এতে Heading মাঝখানে চলে আসবে।

13. Margin কী?

কোনো Element-এর বাইরের Space-কে Margin বলা হয়।

.box {
  margin: 20px;
}

14. Padding কী?

কোনো Element-এর Content এবং Border-এর মধ্যকার Space-কে Padding বলা হয়।

.box {
  padding: 20px;
}
সহজভাবে:
Margin = Element-এর বাইরের Space
Padding = Element-এর ভিতরের Space

15. Border

.box {
  border: 2px solid black;
}

Border ব্যবহার করে কোনো Element-এর চারপাশে রেখা তৈরি করা যায়।

16. Border Radius

.box {
  border-radius: 10px;
}

Border Radius ব্যবহার করলে Box বা Button-এর Corner গোল করা যায়।

17. Width ও Height

.box {
  width: 300px;
  height: 200px;
}

18. Class কী?

একই ধরনের একাধিক Element-এ একই CSS ব্যবহার করার জন্য Class ব্যবহার করা হয়।

<p class="text">Hello</p>
<p class="text">Welcome</p>

CSS:

.text {
  color: blue;
}

19. ID কী?

নির্দিষ্ট একটি Element-এর জন্য ID ব্যবহার করা যায়।

<h1 id="title">Munna Tech</h1>

CSS:

#title {
  color: green;
}

20. CSS Selector

HTML-এর কোন Element-এ CSS প্রয়োগ হবে তা নির্ধারণ করতে Selector ব্যবহার করা হয়।

  • Element Selector
  • Class Selector
  • ID Selector
  • Universal Selector
  • Attribute Selector
p { color: red; }
.box { padding: 20px; }
#title { font-size: 30px; }

21. CSS দিয়ে Button Design

.btn {
  background: blue;
  color: white;
  padding: 12px 20px;
  border: none;
  border-radius: 8px;
  cursor: pointer;
}

22. Hover Effect

Mouse কোনো Button বা Element-এর উপর নিলে Style পরিবর্তন করতে :hover ব্যবহার করা যায়।

.btn:hover {
  background: black;
}

23. CSS Flexbox কী?

Flexbox ব্যবহার করে Element-গুলোকে Row বা Column আকারে সাজানো এবং Layout তৈরি করা সহজ হয়।

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

24. Responsive Design কী?

Website যেন Mobile, Tablet এবং Desktop—সব ধরনের Screen-এ সুন্দরভাবে দেখা যায়, সেটিকে Responsive Design বলা হয়।

@media (max-width: 600px) {
  h1 {
    font-size: 25px;
  }
}

25. Beginnerদের জন্য ছোট CSS Project

নিচের HTML এবং CSS ব্যবহার করে একটি Simple Profile Card তৈরি করার চেষ্টা করুন।

<div class="card">
  <h2>Munna</h2>
  <p>Web Developer</p>
  <button>Contact Me</button>
</div>

CSS:

.card {
  width: 300px;
  padding: 20px;
  text-align: center;
  border: 1px solid #ddd;
  border-radius: 12px;
}

.card button {
  padding: 10px 18px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
}

26. CSS শেখার সময় যে ভুলগুলো করবেন না

  • Property-এর পরে semicolon দিতে ভুল করবেন না
  • Class-এর আগে . ব্যবহার করুন
  • ID-এর আগে # ব্যবহার করুন
  • CSS File-এর সঠিক নাম দিন
  • HTML-এ CSS File-এর সঠিক path দিন
  • Browser Developer Tools ব্যবহার করে সমস্যা খুঁজুন
  • Mobile Screen-এ Website পরীক্ষা করুন

28. CSS শেখার পর কী শিখবেন?

CSS-এর Basic শেখার পর Flexbox, Grid, Responsive Design, Animation এবং Advanced Layout শেখা উচিত।

এরপর JavaScript শিখলে Website-এ Interactive Feature যোগ করতে পারবেন।

Frequently Asked Questions (FAQ)

CSS-এর পূর্ণরূপ কী?

CSS-এর পূর্ণরূপ হলো Cascading Style Sheets।

CSS কেন ব্যবহার করা হয়?

Website-এর Design, Layout, Color, Font, Spacing এবং Responsive behaviour নিয়ন্ত্রণ করার জন্য CSS ব্যবহার করা হয়।

CSS কতভাবে HTML-এ ব্যবহার করা যায়?

Inline CSS, Internal CSS এবং External CSS—এই তিনভাবে CSS ব্যবহার করা যায়।

Class এবং ID-এর মধ্যে পার্থক্য কী?

Class সাধারণত একাধিক Element-এ ব্যবহার করা যায়। ID সাধারণত একটি নির্দিষ্ট Element চিহ্নিত করার জন্য ব্যবহার করা হয়।

CSS শেখা কি কঠিন?

নিয়মিত Practice করলে CSS-এর Basic শেখা সহজ। তবে Professional Design করতে হলে নিয়মিত Project Practice করা গুরুত্বপূর্ণ।

Conclusion

CSS হলো Web Development-এর অত্যন্ত গুরুত্বপূর্ণ একটি অংশ। HTML দিয়ে Website-এর Structure তৈরি করার পর CSS ব্যবহার করে সেটিকে সুন্দর এবং Professional করা যায়।

আপনি যদি Web Developer হতে চান, তাহলে HTML-এর পাশাপাশি CSS ভালোভাবে শেখা এবং ছোট ছোট Project তৈরি করা শুরু করুন।
