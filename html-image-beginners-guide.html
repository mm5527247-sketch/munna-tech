HTML-এ Image যোগ করার নিয়ম

Beginners-এর জন্য HTML Image-এর সম্পূর্ণ সহজ বাংলা গাইড

একটি সুন্দর Website-এ Text-এর পাশাপাশি Image ব্যবহার করলে Website আরও আকর্ষণীয় এবং সহজে বোঝার মতো হয়।

HTML ব্যবহার করে Website-এ Image যোগ করা খুব সহজ। এর জন্য মূলত <img> Tag ব্যবহার করা হয়।

📌 এই Article-এ যা শিখবেন:
  • HTML Image কী?
  • img Tag কীভাবে ব্যবহার করবেন
  • src Attribute
  • alt Attribute
  • Image-এর Width ও Height
  • Local Image ব্যবহার
  • Clickable Image
  • Responsive Image
  • Common Mistakes

1. HTML Image কী?

HTML Page-এ ছবি দেখানোর জন্য <img> Tag ব্যবহার করা হয়।

একটি Basic Image code হলো:

<img src="image.jpg" alt="My Image">

এখানে src দিয়ে Image-এর location এবং alt দিয়ে Image-এর alternative text দেওয়া হয়েছে।

2. img Tag কী?

<img> হলো HTML-এর একটি গুরুত্বপূর্ণ Tag, যেটি Website-এ Image দেখানোর জন্য ব্যবহার করা হয়।

অন্য অনেক HTML Tag-এর মতো <img>-এর আলাদা closing Tag লাগে না।

<img src="photo.jpg" alt="My Photo">

3. src Attribute কী?

src এর অর্থ হলো Source। এটি Browser-কে বলে Image file কোথায় আছে।

<img src="photo.jpg" alt="My Photo">

এখানে photo.jpg হলো Image file-এর নাম।

4. Local Image কীভাবে যোগ করবেন?

আপনার Computer-এর Project Folder-এর মধ্যে Image রাখলে সেটিকে Local Image হিসেবে ব্যবহার করতে পারবেন।

ধরুন আপনার folder structure এমন:

Munna-Tech/ index.html style.css profile.jpg

তাহলে HTML-এ লিখবেন:

<img src="profile.jpg" alt="My Profile Photo">

Image আলাদা Folder-এর মধ্যে থাকলে

ধরুন Project-এর মধ্যে images নামে একটি Folder আছে।

Munna-Tech/ index.html images/ profile.jpg

তখন code হবে:

<img src="images/profile.jpg" alt="My Profile Photo">

5. alt Attribute কী?

alt হলো alternative text। Image load না হলে অথবা Image দেখা না গেলে এই text-এর মাধ্যমে Image সম্পর্কে ধারণা পাওয়া যায়।

<img src="computer.jpg" alt="A desktop computer">
💡 গুরুত্বপূর্ণ:

Image ব্যবহার করার সময় meaningful alt text দেওয়া ভালো। যেমন alt="My Profile Photo"।

6. Image-এর Size পরিবর্তন করা

HTML Attribute ব্যবহার করে Image-এর width এবং height নির্ধারণ করা যায়।

<img src="photo.jpg" alt="My Photo" width="500" height="300">

শুধু Width দেওয়া

<img src="photo.jpg" alt="My Photo" width="500">

অনেক ক্ষেত্রে শুধু width নির্ধারণ করে height auto রাখা সুবিধাজনক।

7. CSS দিয়ে Image Size পরিবর্তন

Professional Website-এ Image styling করার জন্য CSS ব্যবহার করা বেশি সুবিধাজনক।

<img class="my-image" src="photo.jpg" alt="My Photo">

CSS:

.my-image { width: 400px; max-width: 100%; height: auto; }

8. Responsive Image কী?

Website Mobile, Tablet এবং Computer-এ বিভিন্ন Screen Size-এ দেখা হয়। তাই Image যেন Screen-এর বাইরে চলে না যায়, সেজন্য Responsive Image ব্যবহার করা ভালো।

img { max-width: 100%; height: auto; }

এতে Image তার container-এর চেয়ে বেশি বড় হবে না।

9. Image Center করার নিয়ম

CSS ব্যবহার করে Image Center করা যায়।

.my-image { display: block; margin: 20px auto; }

10. Image-এ Border ও Rounded Corner

CSS দিয়ে Image-কে আরও সুন্দর করা যায়।

.my-image { max-width: 100%; border-radius: 15px; }

border-radius ব্যবহার করলে Image-এর Corner গোল হবে।

11. Clickable Image তৈরি করা

Image-এর উপর Click করলে অন্য Page বা Website-এ যাওয়ার ব্যবস্থা করা যায়।

<a href="index.html"> <img src="logo.png" alt="Munna Tech Logo"> </a>

Image Link নতুন Tab-এ খুলতে

<a href="https://example.com" target="_blank" rel="noopener noreferrer"> <img src="photo.jpg" alt="Example Image"> </a>

12. কোন Image Format ব্যবহার করবেন?

Website-এর জন্য বিভিন্ন Image format ব্যবহার করা যায়।

  • JPG/JPEG: সাধারণ Photo-এর জন্য ভালো।
  • PNG: Transparent background প্রয়োজন হলে উপকারী।
  • WebP: অনেক ক্ষেত্রে Website-এর জন্য ভালো compression দিতে পারে।

13. Beginners-এর Common Mistakes

  • Image file-এর নাম ভুল লেখা
  • File extension ভুল দেওয়া
  • Folder path ভুল লেখা
  • src-এ ভুল location দেওয়া
  • alt না দেওয়া
  • খুব বড় Image ব্যবহার করে Page ধীর করা

14. Image দেখা না গেলে কী করবেন?

যদি Browser-এ Image না দেখা যায়, তাহলে প্রথমে নিচের বিষয়গুলো পরীক্ষা করুন।

  1. Image file-এর নাম ঠিক আছে কিনা।
  2. JPG/PNG/WebP extension ঠিক আছে কিনা।
  3. Image সঠিক Folder-এ আছে কিনা।
  4. src path ঠিক আছে কিনা।

Example

যদি আপনার Image-এর নাম হয়:

profile.png

তাহলে:

<img src="profile.png" alt="Profile Photo">

15. Complete HTML Image Example

নিচের code-টি ব্যবহার করে একটি simple Image Page তৈরি করতে পারেন।

<!DOCTYPE html> <html lang="bn"> <head> <meta charset="UTF-8"> <title>My Photo</title> </head> <body> <h1>My Profile</h1> <p> This is my profile photo. </p> <img src="profile.jpg" alt="My Profile Photo" width="400"> </body> </html>

  2. একটি Photo সেখানে রাখুন।
  3. <img> Tag দিয়ে Photo দেখান।
  4. একটি meaningful alt লিখুন।

❓ Frequently Asked Questions

HTML-এ Image যোগ করার Tag কোনটি?

Image যোগ করার জন্য <img> Tag ব্যবহার করা হয়।

src কী?

src Image-এর source বা location নির্ধারণ করে।

alt কেন ব্যবহার করা হয়?

Image দেখা না গেলে alternative text হিসেবে alt ব্যবহার করা হয়।

Image Responsive করার সহজ উপায় কী?

CSS-এ max-width: 100%; এবং height: auto; ব্যবহার করা যায়।

শেষ কথা

এরপর CSS ব্যবহার করে Image-এর Size, Border, Rounded Corner এবং Responsive Design আরও সুন্দরভাবে তৈরি করতে পারবেন।
