PC-তে Screenshot নেওয়ার 7টি সহজ উপায় | Windows 11 Guide

PC ব্যবহার করার সময় অনেক সময় screen-এর কোনো গুরুত্বপূর্ণ অংশ ছবি হিসেবে save করার প্রয়োজন হয়। যেমন কোনো error message, website-এর অংশ, online class, tutorial বা গুরুত্বপূর্ণ information।

Windows 11-এ Screenshot নেওয়ার জন্য আলাদা কোনো complicated software সবসময় প্রয়োজন হয় না। Windows-এর built-in tools এবং keyboard shortcuts ব্যবহার করেই সহজে screenshot নেওয়া যায়।

``` এই Article-এ আপনি শিখবেন:
  • Screenshot কী?
  • Win + Shift + S ব্যবহার
  • PrtSc key ব্যবহার
  • Windows + PrtSc
  • Snipping Tool
  • Active window screenshot
  • Screenshot কোথায় save হয়
  • Screenshot-এর common problems
```

1. Screenshot কী?

Screenshot হলো আপনার computer screen-এর একটি নির্দিষ্ট মুহূর্তের digital image।

আপনি screen-এর পুরো অংশ অথবা শুধু একটি নির্দিষ্ট অংশ capture করতে পারেন।

2. সবচেয়ে সহজ উপায় — Win + Shift + S

Windows 11-এ নির্দিষ্ট screen area capture করার জন্য Windows + Shift + S shortcut খুবই useful।

``` Win + Shift + S

এই shortcut চাপলে screen-এর উপরের অংশে screenshot selection options দেখা যেতে পারে।

```

কীভাবে ব্যবহার করবেন?

    ```
  1. Win + Shift + S চাপুন।
  2. Screen-এর প্রয়োজনীয় অংশ select করুন।
  3. Screenshot capture হবে।
  4. Notification বা Snipping Tool interface থেকে screenshot edit বা save করতে পারেন।
    5. ```

3. PrtSc Key দিয়ে Screenshot

Keyboard-এ অনেক সময় PrtSc, PrtScn অথবা একই ধরনের label থাকা key থাকে।

এটি ব্যবহার করে screen capture করা যায়। Keyboard এবং Windows configuration অনুযায়ী capture-এর behaviour কিছুটা ভিন্ন হতে পারে।

``` Tip: আপনার keyboard-এ PrtSc key-এর নাম একটু ভিন্ন হতে পারে। Laptop keyboard-এ কখনো Fn key-এর প্রয়োজন হতে পারে। ```

4. Windows + PrtSc দিয়ে Screenshot Save করুন

Windows + PrtSc shortcut ব্যবহার করে পুরো screen capture করার একটি সহজ উপায় পাওয়া যায়।

Win + PrtSc

অনেক Windows setup-এ এই ধরনের screenshot automatically Pictures-এর Screenshots folder-এ save হতে পারে। 

Pictures
   ↓
Screenshots
``` মনে রাখুন: Windows version, keyboard এবং system configuration অনুযায়ী screenshot save বা capture behaviour কিছুটা আলাদা হতে পারে। ```

5. Snipping Tool ব্যবহার করুন

Windows-এর built-in Snipping Tool screenshot নেওয়ার জন্য একটি useful application।

Windows Search থেকে: 

Snipping Tool

লিখে applicationটি open করতে পারেন।

Snipping Tool ব্যবহার করে সাধারণত screen-এর নির্দিষ্ট অংশ capture করা, screenshot edit করা এবং save করার সুবিধা পাওয়া যায়।

6. Active Window Screenshot

কখনো পুরো desktop নয়, শুধু বর্তমানে ব্যবহার করা application window-এর screenshot নেওয়ার প্রয়োজন হতে পারে।

Windows-এর screenshot shortcuts-এর মাধ্যমে active window capture করার পদ্ধতি keyboard configuration অনুযায়ী ব্যবহার করা যায়।

``` Practical Example: আপনি যদি শুধু Chrome window-এর screenshot নিতে চান, তাহলে পুরো desktop capture করার পরিবর্তে active window capture করার পদ্ধতি বেশি convenient হতে পারে। ```

7. Screenshot নিয়ে Edit করুন

Screenshot নেওয়ার পরে অনেক সময় কিছু অংশ crop করা, গুরুত্বপূর্ণ জায়গা highlight করা বা text যোগ করার প্রয়োজন হয়।

Snipping Tool-এর editing features ব্যবহার করে basic editing করা যেতে পারে।

8. Screenshot কোথায় Save হয়?

Screenshot কীভাবে নেওয়া হয়েছে তার ওপর save location নির্ভর করতে পারে।

Windows-এর automatic screenshot save হলে সাধারণত Pictures → Screenshots folder-এ পাওয়া যেতে পারে।

অন্যদিকে Snipping Tool ব্যবহার করলে screenshot save করার সময় location নির্বাচন করার option থাকতে পারে।

9. Screenshot Copy করে Paste করা

কিছু screenshot method screen capture-কে clipboard-এ রাখতে পারে। তখন কোনো supported application-এ গিয়ে paste করা যায়। 

Screenshot
    ↓
Clipboard
    ↓
Ctrl + V
    ↓
Supported App

উদাহরণ হিসেবে image editor বা document application-এ screenshot paste করা যেতে পারে।

  2. শুধু প্রয়োজনীয় অংশ capture করলে image পরিষ্কার হয়।
  3. Important information থাকলে screenshot share করার আগে sensitive information check করুন।
  4. অনেক screenshot হলে meaningful filename ব্যবহার করুন।
  5. Important screenshots প্রয়োজন হলে আলাদা folder-এ organize করুন।

13. Screenshot Share করার আগে সতর্ক থাকুন

Screenshot-এর মধ্যে password, phone number, email address, verification code অথবা অন্য কোনো sensitive information থাকলে share করার আগে সেটি hide বা crop করুন।

``` Security Tip: Screenshot-এর মধ্যে থাকা private information public website, social media বা unknown person-এর কাছে share করার আগে ভালোভাবে check করুন। ```

14. Screenshot Keyboard Shortcut কাজ না করলে

যদি keyboard shortcut কাজ না করে, তাহলে কয়েকটি বিষয় পরীক্ষা করতে পারেন।

    ```
  • Keyboard-এর PrtSc key আছে কিনা দেখুন
  • Laptop হলে Fn key প্রয়োজন কিনা পরীক্ষা করুন
  • Windows Search থেকে Snipping Tool open করে দেখুন
  • Windows Update pending আছে কিনা দেখুন
  • Keyboard নিজে ঠিকমতো কাজ করছে কিনা পরীক্ষা করুন
    • ```

15. Screenshot নেওয়ার জন্য Third-party Software দরকার?

Basic screenshot-এর জন্য Windows-এর built-in tools অনেক ক্ষেত্রেই যথেষ্ট।

Advanced annotation, screen recording বা workflow-এর বিশেষ প্রয়োজন থাকলে third-party software বিবেচনা করা যেতে পারে।
