CSS দিয়ে Website Design করার সহজ নিয়ম

HTML দিয়ে Website-এর Structure তৈরি করার পর Website-কে সুন্দর ও Professional করার জন্য CSS ব্যবহার করা হয়।

এই গাইডে আমরা Beginner level থেকে CSS ব্যবহার করে Website Design করার গুরুত্বপূর্ণ বিষয়গুলো শিখব।

1. Website Design-এর জন্য CSS কেন গুরুত্বপূর্ণ?

একটি Website শুধু তথ্য দেখালেই যথেষ্ট নয়। Website যেন দেখতে সুন্দর, পড়তে সহজ এবং Mobile ও Desktop উভয় জায়গায় ঠিকভাবে কাজ করে, সেজন্য CSS গুরুত্বপূর্ণ।

  • Color ও Background পরিবর্তন
  • Font ও Text Style
  • Button Design
  • Card Design
  • Navbar Design
  • Spacing
  • Flexbox Layout
  • Hover Effect
  • Responsive Design

2. প্রথমে Website-এর Basic Structure তৈরি করুন

CSS দেওয়ার আগে HTML-এর মাধ্যমে Website-এর প্রয়োজনীয় Structure তৈরি করতে হবে।

<header>Website Header</header>
<nav>Navigation</nav>
<main>Main Content</main>
<footer>Footer</footer>

3. External CSS ব্যবহার করুন

Professional Website-এর জন্য আলাদা CSS File ব্যবহার করা ভালো।

<link rel="stylesheet" href="style.css">

এতে HTML File পরিষ্কার থাকে এবং একই CSS অনেকগুলো Page-এ ব্যবহার করা যায়।

4. Website-এর Main Font ঠিক করুন

body {
  font-family: Arial, sans-serif;
  line-height: 1.6;
}

ভালো Font এবং Line Height Website-এর Content পড়তে সহজ করে।

5. Website-এর Background Color

body {
  background-color: #f8fafc;
}

খুব বেশি উজ্জ্বল Background ব্যবহার না করে Content পড়ার জন্য আরামদায়ক Background ব্যবহার করা ভালো।

6. Color Palette নির্বাচন

Website Design করার সময় কয়েকটি নির্দিষ্ট Color ব্যবহার করলে Design বেশি Consistent দেখায়।

:root {
  --primary: #2563eb;
  --dark: #111827;
  --light: #f8fafc;
  --text: #1f2937;
}

CSS Variable ব্যবহার করলে পরে পুরো Website-এর Color পরিবর্তন করা সহজ হয়।

7. Professional Navbar তৈরি

Website-এর Navigation User-কে বিভিন্ন Page-এ যেতে সাহায্য করে।

nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 15px 25px;
  background: #111827;
}

nav a {
  color: white;
  text-decoration: none;
}

9. CSS Flexbox ব্যবহার করুন

Website-এর বিভিন্ন Element পাশাপাশি সাজানোর জন্য Flexbox খুবই গুরুত্বপূর্ণ।

.container {
  display: flex;
  gap: 20px;
  flex-wrap: wrap;
}

10. Card Design

Tutorial, Product, Service বা Feature দেখানোর জন্য Card Design ব্যবহার করা যায়।

.card {
  padding: 20px;
  background: white;
  border-radius: 12px;
  box-shadow: 0 4px 15px rgba(0,0,0,0.08);
}

12. Margin এবং Padding ঠিকভাবে ব্যবহার

Website-এর বিভিন্ন অংশের মধ্যে Space রাখার জন্য Margin এবং Padding ব্যবহার করা হয়।

.section {
  margin: 40px 0;
  padding: 30px;
}
মনে রাখুন:
Margin = Element-এর বাইরের Space
Padding = Element-এর ভিতরের Space

13. Button Design

.btn {
  padding: 12px 20px;
  background: #2563eb;
  color: white;
  border: none;
  border-radius: 8px;
  cursor: pointer;
}

14. Hover Effect

Mouse কোনো Button বা Link-এর উপর নিলে Style পরিবর্তন করার জন্য :hover ব্যবহার করা হয়।

.btn:hover {
  transform: translateY(-2px);
  opacity: 0.9;
}
Hover Me

15. Border Radius দিয়ে Design সুন্দর করুন

.card {
  border-radius: 15px;
}

Border Radius ব্যবহার করলে Box, Image, Card এবং Button-এর Corner সুন্দরভাবে Round করা যায়।

16. Box Shadow

Card বা Box-কে Background থেকে আলাদা করে দেখানোর জন্য Box Shadow ব্যবহার করা যায়।

.card {
  box-shadow: 0 4px 15px rgba(0,0,0,0.08);
}

17. Image Design

img {
  max-width: 100%;
  height: auto;
  border-radius: 10px;
}

max-width: 100% ব্যবহার করলে Image ছোট Screen-এ Container-এর বাইরে চলে যাওয়ার সম্ভাবনা কমে।

18. Content-এর Maximum Width নির্ধারণ

Website-এর Content অনেক বেশি চওড়া হলে পড়তে অসুবিধা হতে পারে। তাই Container-এর Maximum Width নির্ধারণ করা যায়।

.container {
  max-width: 1100px;
  margin: auto;
  padding: 20px;
}

19. Responsive Website তৈরি

Website যেন Mobile, Tablet এবং Desktop-এ ভালোভাবে দেখা যায়, তার জন্য Media Query ব্যবহার করা হয়।

@media (max-width: 700px) {
  .container {
    padding: 15px;
  }

  h1 {
    font-size: 28px;
  }
}

20. Mobile Menu-এর জন্য Basic ধারণা

Mobile Screen-এ Navbar-এর Link অনেক সময় ছোট জায়গায় ঠিকমতো দেখা যায় না। তাই Responsive Navbar তৈরি করতে Media Query এবং পরে JavaScript ব্যবহার করা যায়।

@media (max-width: 600px) {
  nav ul {
    flex-direction: column;
  }
}

21. CSS Transition

কোনো Element-এর Style পরিবর্তনকে Smooth করার জন্য Transition ব্যবহার করা যায়।

.btn {
  transition: 0.3s;
}

25. CSS শেখার পর কী শিখবেন?

CSS Basic শেখার পর Flexbox, CSS Grid, Responsive Design, Animation এবং Advanced Layout শেখা উচিত।

এরপর JavaScript শেখা শুরু করলে Website-এ Interactive Features, Form Validation, Menu Toggle এবং অন্যান্য Dynamic Function যোগ করতে পারবেন।

Frequently Asked Questions (FAQ)

CSS কী?

CSS হলো Cascading Style Sheets। Website-এর Design ও Layout পরিবর্তনের জন্য CSS ব্যবহার করা হয়।

CSS দিয়ে কী কী করা যায়?

Color, Font, Background, Button, Card, Navbar, Spacing, Layout, Responsive Design এবং অনেক ধরনের Visual Style তৈরি করা যায়।

Website Design করার জন্য HTML নাকি CSS?

HTML Website-এর Structure তৈরি করে এবং CSS সেই Structure-এর Design ও Presentation নিয়ন্ত্রণ করে। দুটো একসাথে ব্যবহার করা হয়।

CSS-এর জন্য আলাদা File ব্যবহার করা ভালো?

বড় Website-এর ক্ষেত্রে External CSS File ব্যবহার করলে Code Organize করা সহজ হয় এবং একাধিক Page-এ একই Style ব্যবহার করা যায়।

CSS দিয়ে Mobile Responsive Website বানানো যায়?

হ্যাঁ। Media Query, Flexible Layout, Flexbox, Grid এবং Responsive Units ব্যবহার করে Mobile Responsive Website তৈরি করা যায়।

Conclusion

CSS শেখার মূল বিষয় হলো শুধু Property মুখস্থ করা নয়, বরং সেগুলো ব্যবহার করে ছোট ছোট Project তৈরি করা।

আপনি যদি প্রতিদিন একটি করে ছোট Design তৈরি করেন, তাহলে ধীরে ধীরে Professional Website Design করার দক্ষতা তৈরি হবে।
