CSS কী? Beginner-এর জন্য সহজ গাইড

CSS ব্যবহার করে HTML webpage-এর design এবং appearance পরিবর্তন করা হয়। Color, font, spacing, size এবং layout পরিবর্তন করতে CSS ব্যবহার করা যায়।

CSS-এর পূর্ণরূপ কী?

CSS-এর পূর্ণরূপ হলো Cascading Style Sheets।

CSS কেন প্রয়োজন?

শুধু HTML ব্যবহার করলে webpage-এর structure তৈরি হয়। CSS ব্যবহার করলে সেই webpage আরও সুন্দর এবং user-friendly করা যায়।

Basic CSS Example


h1 {
    color: blue;
    font-size: 40px;
}

Color পরিবর্তন


p {
    color: green;
}

Font Size পরিবর্তন


p {
    font-size: 20px;
}

Background Color


body {
    background-color: lightgray;
}

Text Alignment


h1 {
    text-align: center;
}

Padding কী?

Element-এর ভিতরের space তৈরি করতে padding ব্যবহার করা হয়। 


.box {
    padding: 20px;
}

Margin কী?

একটি element-এর বাইরে space তৈরি করতে margin ব্যবহার করা হয়। 


.box {
    margin: 20px;
}

CSS শেখার পর কী করবেন?

CSS-এর basic শেখার পরে Flexbox, Grid এবং Responsive Design শেখা গুরুত্বপূর্ণ।

শেষ কথা

HTML এবং CSS একসাথে practice করলে webpage design করা অনেক সহজ হয়ে যায়।
