CSS কী? Beginner Guide

HTML দিয়ে website-এর structure তৈরি করার পর website সুন্দর ও professional করার জন্য CSS শেখা প্রয়োজন। এই guide-এ সহজভাবে CSS সম্পর্কে জানব।

CSS কী?

CSS-এর পূর্ণরূপ হলো Cascading Style Sheets।

CSS ব্যবহার করে website-এর color, font, size, spacing, layout এবং responsive design তৈরি করা যায়।

CSS কেন ব্যবহার করা হয়?

শুধু HTML ব্যবহার করলে website সাধারণ দেখতে হতে পারে। CSS ব্যবহার করে website-এর design সুন্দর করা যায়।

CSS-এর Basic Syntax

p {
    color: blue;
    font-size: 18px;
}

Text Color পরিবর্তন

color property ব্যবহার করে text-এর color পরিবর্তন করা যায়। 

h1 {
    color: blue;
}

Background Color

background-color ব্যবহার করে কোনো element-এর background color পরিবর্তন করা যায়। 

body {
    background-color: lightgray;
}

Font Size

Text-এর আকার পরিবর্তনের জন্য font-size ব্যবহার করা হয়। 

p {
    font-size: 18px;
}

Text Alignment

Text কোথায় থাকবে তা নির্ধারণ করতে text-align ব্যবহার করা হয়। 

h1 {
    text-align: center;
}

Margin এবং Padding

Element-এর বাইরের space-এর জন্য margin এবং ভেতরের space-এর জন্য padding ব্যবহার করা হয়। 

.box {
    margin: 20px;
    padding: 20px;
}

Border তৈরি করা

কোনো element-এর চারপাশে border দেওয়ার জন্য border property ব্যবহার করা হয়। 

.box {
    border: 1px solid black;
}

CSS দিয়ে Button Design

.btn {
    background: blue;
    color: white;
    padding: 12px 20px;
    border-radius: 8px;
}

Responsive Design

Responsive design ব্যবহার করলে website computer, tablet এবং mobile screen-এ সুন্দরভাবে দেখা যায়। 

@media (max-width: 768px) {

    h1 {
        font-size: 28px;
    }

}

CSS শেখার পর কী শিখবেন?

HTML এবং CSS-এর basic শেখার পর JavaScript শেখা শুরু করুন।

JavaScript ব্যবহার করে website-এ interactive features এবং বিভিন্ন functionality যোগ করা যায়।

💡 Beginner Tip

CSS শেখার সবচেয়ে ভালো উপায় হলো নিজে হাতে practice করা। একটি ছোট HTML page তৈরি করে প্রতিদিন নতুন CSS property ব্যবহার করে দেখুন।
