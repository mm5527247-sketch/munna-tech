HTML Heading, Paragraph ও Link কীভাবে ব্যবহার করবেন?

Beginners-এর জন্য HTML Heading, Paragraph এবং Link-এর সহজ বাংলা গাইড

HTML শেখার সময় সবচেয়ে বেশি ব্যবহার করা হয় Heading, Paragraph এবং Link। একটি সাধারণ Website তৈরি করতে এই তিনটি বিষয় জানা খুবই গুরুত্বপূর্ণ।

এই Article-এ আমরা একদম Beginner level থেকে শিখব কীভাবে HTML-এ Heading, Paragraph এবং Link ব্যবহার করতে হয়।

📌 এই Article-এ যা শিখবেন:
  • HTML Heading কী?
  • H1 থেকে H6 কী?
  • Paragraph কীভাবে লিখবেন?
  • HTML Link কী?
  • External এবং Internal Link
  • Link নতুন Tab-এ খোলা
  • Practical Website Example

1. HTML Heading কী?

Website-এর বিভিন্ন শিরোনাম বা Title দেখানোর জন্য HTML Heading ব্যবহার করা হয়।

HTML-এ মোট ছয় ধরনের Heading আছে:

<h1>Heading 1</h1> <h2>Heading 2</h2> <h3>Heading 3</h3> <h4>Heading 4</h4> <h5>Heading 5</h5> <h6>Heading 6</h6>

<h1> H1 Heading

<h1> হলো সবচেয়ে গুরুত্বপূর্ণ Heading। সাধারণত একটি Page-এর প্রধান Title-এর জন্য এটি ব্যবহার করা হয়।

<h1>Munna Tech</h1>

<h2> H2 Heading

Page-এর গুরুত্বপূর্ণ Section-এর Heading হিসেবে <h2> ব্যবহার করা যায়।

<h2>HTML Tutorial</h2>

<h3> H3 Heading

কোনো Section-এর ভিতরের Sub-section-এর জন্য <h3> ব্যবহার করা যায়।

<h3>HTML Tags</h3>

H4, H5 এবং H6

আরও ছোট বা nested heading প্রয়োজন হলে <h4>, <h5> এবং <h6> ব্যবহার করা হয়।

Heading-এর সম্পূর্ণ Example

<h1>My Website</h1> <h2>About Me</h2> <h3>My Skills</h3> <h4>HTML</h4> <h5>CSS</h5> <h6>JavaScript</h6>
💡 SEO Tip:

Heading শুধু বড় লেখা দেখানোর জন্য নয়। Website-এর content structure বোঝাতেও Heading গুরুত্বপূর্ণ। তাই Heading-এর ব্যবহার logical রাখা ভালো।

2. HTML Paragraph কী?

Website-এ সাধারণ লেখা বা paragraph দেখানোর জন্য <p> Tag ব্যবহার করা হয়।

<p> আমি Web Development শিখছি। </p>

একাধিক Paragraph

একটি Website-এ যতগুলো আলাদা paragraph প্রয়োজন, ততগুলো <p> Tag ব্যবহার করা যায়।

<p> আমি HTML শিখছি। </p> <p> এরপর আমি CSS শিখব। </p> <p> তারপর JavaScript শিখব। </p>

Browser-এ ফলাফল

আমি HTML শিখছি।

এরপর আমি CSS শিখব।

তারপর JavaScript শিখব।

Paragraph-এর মধ্যে নতুন Line

নতুন লাইনে যাওয়ার জন্য <br> ব্যবহার করা যায়।

Hello<br> World

3. HTML Link কী?

একটি Website থেকে অন্য Website অথবা অন্য Page-এ যাওয়ার জন্য HTML Link ব্যবহার করা হয়।

Link তৈরি করার জন্য <a> বা Anchor Tag ব্যবহার করা হয়।

Basic Link

<a href="https://example.com"> Visit Website </a>

href কী?

href হলো একটি HTML Attribute। এটি Link-এর destination বা গন্তব্য নির্ধারণ করে।

<a href="https://google.com"> Google </a>

4. External Link কী?

আপনার Website থেকে অন্য Website-এ যাওয়ার Link-কে External Link বলা হয়।

<a href="https://www.google.com"> Google </a>

Link নতুন Tab-এ Open করা

Link-টি নতুন Browser Tab-এ খুলতে target="_blank" ব্যবহার করা যায়।

<a href="https://www.google.com" target="_blank" rel="noopener noreferrer"> Google </a>

5. Internal Link কী?

একই Website-এর একটি Page থেকে অন্য Page-এ যাওয়ার Link-কে Internal Link বলা হয়।

❓ Frequently Asked Questions

HTML-এ কয়টি Heading আছে?

HTML-এ H1 থেকে H6 পর্যন্ত মোট ছয় ধরনের Heading আছে।

Paragraph-এর জন্য কোন Tag ব্যবহার হয়?

Paragraph-এর জন্য <p> Tag ব্যবহার করা হয়।

HTML Link-এর জন্য কোন Tag ব্যবহার হয়?

Link তৈরি করার জন্য <a> বা Anchor Tag ব্যবহার করা হয়।

Link নতুন Tab-এ কীভাবে খুলব?

target="_blank" ব্যবহার করলে Link নতুন Tab-এ খোলা যায়।
