HTML-এর 20টি গুরুত্বপূর্ণ Tag যা Beginners-এর জানা দরকার

সহজ বাংলায় HTML-এর সবচেয়ে গুরুত্বপূর্ণ 20টি Tag শিখুন

আপনি যদি নতুন করে Web Development শেখা শুরু করেন, তাহলে HTML হলো আপনার প্রথম গুরুত্বপূর্ণ ধাপ। HTML দিয়ে একটি Website-এর মূল structure তৈরি করা হয়।

HTML শেখার সময় অনেকগুলো Tag দেখতে পাওয়া যায়। তবে শুরুতে সব Tag শেখার প্রয়োজন নেই। কিছু গুরুত্বপূর্ণ Tag ভালোভাবে বুঝে practice করলেই আপনি সহজ HTML Website তৈরি করতে পারবেন।

<html>

1. HTML Tag

<html> হলো একটি HTML document-এর মূল বা root element।

<html> Website content </html>
<head>

2. Head Tag

<head> এর মধ্যে Website-এর বিভিন্ন গুরুত্বপূর্ণ information থাকে।

<head> <title>My Website</title> </head>
<title>

3. Title Tag

Browser tab-এ Website-এর নাম দেখানোর জন্য <title> ব্যবহার করা হয়।

<title>Munna Tech</title>
<body>

4. Body Tag

Website-এর যেসব content visitor দেখতে পাবে, সেগুলো সাধারণত <body>-এর মধ্যে থাকে।

<body> <h1>Hello World</h1> </body>
<h1>

5. Heading Tag

Heading তৈরি করার জন্য <h1> থেকে <h6> পর্যন্ত Tag ব্যবহার করা হয়।

<h1>My Website</h1> <h2>About Me</h2> <h3>My Skills</h3>
<p>

6. Paragraph Tag

Paragraph বা সাধারণ লেখা দেখানোর জন্য <p> Tag ব্যবহার করা হয়।

<p> আমি Web Development শিখছি। </p>
<a>

7. Anchor Tag

অন্য Website বা অন্য Page-এর সাথে link তৈরি করতে <a> Tag ব্যবহার করা হয়।

<a href="https://example.com"> Visit Website </a>
<img>

8. Image Tag

Website-এ ছবি দেখানোর জন্য <img> Tag ব্যবহার করা হয়।

<img src="image.jpg" alt="My Photo">
<br>

9. Line Break Tag

নতুন লাইনে যাওয়ার জন্য <br> ব্যবহার করা হয়।

Hello<br> World
<hr>

10. Horizontal Rule

Content-এর মধ্যে একটি horizontal line তৈরি করতে <hr> ব্যবহার করা হয়।

<hr>
<strong>

11. Strong Tag

গুরুত্বপূর্ণ text বোঝাতে <strong> ব্যবহার করা হয়।

<strong>Important Text</strong>
<em>

12. Emphasis Tag

কোনো text-এ emphasis বা বিশেষ গুরুত্ব দিতে <em> ব্যবহার করা হয়।

<em>Learn HTML</em>
<ul>

13. Unordered List

Bullet list তৈরি করতে <ul> ব্যবহার করা হয়।

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>
<ol>

14. Ordered List

Numbered list তৈরি করার জন্য <ol> ব্যবহার করা হয়।

<ol> <li>Learn HTML</li> <li>Learn CSS</li> <li>Learn JavaScript</li> </ol>
<li>

15. List Item Tag

List-এর প্রতিটি item তৈরি করতে <li> ব্যবহার করা হয়।

<ul> <li>Gaming</li> <li>Coding</li> </ul>
<div>

16. Div Tag

Website-এর বিভিন্ন section বা content group করার জন্য <div> খুব বেশি ব্যবহার করা হয়।

<div> <h2>About Me</h2> <p>I am learning Web Development.</p> </div>
<span>

17. Span Tag

কোনো ছোট অংশের text আলাদাভাবে style করার জন্য <span> ব্যবহার করা হয়।

<p> I love <span>Web Development</span>. </p>
<button>

18. Button Tag

Website-এ button তৈরি করতে <button> ব্যবহার করা হয়।

<button>Click Me</button>
<form>

19. Form Tag

User-এর কাছ থেকে information নেওয়ার জন্য form তৈরি করতে <form> ব্যবহার করা হয়।

<form> <input type="text" placeholder="Your Name"> <button type="submit"> Submit </button> </form>
<input>

20. Input Tag

User-এর কাছ থেকে name, email, password ইত্যাদি information নেওয়ার জন্য <input> ব্যবহার করা হয়।

<input type="text" placeholder="Enter your name"> <input type="email" placeholder="Enter your email">

🎯 এই 20টি Tag মনে রাখার সহজ উপায়

শুরুতে সব HTML Tag মুখস্থ করার দরকার নেই। আগে এই 20টি Tag নিয়মিত practice করুন।

  • Structure → html, head, title, body
  • Text → h1, h2, h3, p, strong, em
  • Link & Image → a, img
  • List → ul, ol, li
  • Layout → div, span
  • Interaction → button, form, input
  • Other → br, hr

🧑‍💻 Beginner Practice Task

এখন নিজে একটি ছোট Website তৈরি করুন। সেখানে নিচের বিষয়গুলো রাখুন:

  1. একটি Heading
  2. একটি Paragraph
  3. একটি Image
  4. একটি Link
  5. একটি List
  6. একটি Button
  7. একটি Input Box

নিজে code লিখে Browser-এ খুলে result দেখুন। এভাবেই practice করলে HTML দ্রুত বুঝতে পারবেন।

💡 Pro Tip:

শুধু code দেখে HTML শেখা যায় না। প্রতিটি Tag নিজে লিখে Browser-এ result দেখুন। ভুল হলে সেই ভুল থেকেই শেখার চেষ্টা করুন।

❓ Frequently Asked Questions

HTML Tag কী?

HTML Tag হলো এমন একটি markup element যার মাধ্যমে Browser-কে Website-এর content কীভাবে structure করতে হবে তা বোঝানো হয়।

HTML শেখার জন্য কতগুলো Tag জানা দরকার?

Beginner হিসেবে প্রথমে গুরুত্বপূর্ণ কয়েকটি Tag ভালোভাবে শেখাই যথেষ্ট। পরে প্রয়োজন অনুযায়ী আরও Tag শেখা যায়।

HTML শেখার পর কী শিখব?

HTML-এর basic ভালোভাবে শেখার পর CSS শেখা উচিত। CSS দিয়ে Website-এর design ও layout তৈরি করা যায়। এরপর JavaScript শিখলে Website-এ interaction যোগ করতে পারবেন।

শেষ কথা

HTML হলো Web Development শেখার অন্যতম গুরুত্বপূর্ণ ভিত্তি। এই Article-এর 20টি Tag ভালোভাবে practice করলে আপনি নিজের basic Website তৈরি করার জন্য একটি শক্ত foundation পাবেন।

এরপর HTML-এর পাশাপাশি CSS এবং JavaScript শেখার মাধ্যমে ধীরে ধীরে professional Website তৈরি করতে পারবেন।
