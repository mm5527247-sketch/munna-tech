```
JavaScript Variable: var, let, const কী?

JavaScript শেখার সময় Variable একটি খুব গুরুত্বপূর্ণ বিষয়। Variable ব্যবহার করে আমরা বিভিন্ন ধরনের data বা value সংরক্ষণ করতে পারি।

JavaScript-এ variable তৈরি করার জন্য বর্তমানে সবচেয়ে বেশি let এবং const ব্যবহার করা হয়। পুরোনো JavaScript code-এ var-ও অনেক দেখা যায়।

এই article-এ আপনি শিখবেন:
  • Variable কী
  • var কী
  • let কী
  • const কী
  • var, let, const-এর পার্থক্য
  • Variable-এর value পরিবর্তন
  • Variable naming rules
  • Scope-এর basic ধারণা

  • Practice project

1. JavaScript Variable কী?

Variable হলো data রাখার জন্য একটি নাম দেওয়া storage বা reference। সহজভাবে বললে, একটি value-কে একটি নাম দিয়ে পরে সেই নাম ব্যবহার করা যায়। 

let name = "Munna";

এখানে name হলো variable এবং "Munna" হলো তার value।

2. Variable কেন ব্যবহার করা হয়?

Website বা application-এ বিভিন্ন data নিয়ে কাজ করার জন্য variable দরকার।

  • User-এর নাম রাখা
  • বয়স রাখা
  • Score রাখা
  • Price রাখা
  • Website settings রাখা
  • Calculation-এর result রাখা
let name = "Munna";
```

let age = 20;
let score = 95;
```

3. let কী?

let ব্যবহার করে এমন variable তৈরি করা যায় যার value পরে পরিবর্তন করা প্রয়োজন হতে পারে। 

let age = 20;
```

age = 21;

console.log(age);
```

এখানে প্রথমে age-এর value 20 ছিল। পরে সেটি 21 করা হয়েছে।

4. const কী?

const ব্যবহার করে এমন variable তৈরি করা হয় যেটিকে পরে নতুন value দিয়ে reassign করার প্রয়োজন নেই। 

const country = "Bangladesh";
```

console.log(country);
```

নিচের code-টি ভুল হবে: 

const country = "Bangladesh";
```

country = "India";
```

কারণ const variable-কে নতুন value দিয়ে reassign করা যায় না।

5. var কী?

var হলো JavaScript-এর পুরোনো variable declaration keyword। পুরোনো code এবং project-এ এটি দেখা যায়। 

var name = "Munna";
```

console.log(name);
```

Modern JavaScript code-এ সাধারণত variable declaration-এর ক্ষেত্রে let এবং const বেশি ব্যবহার করা হয়।

6. var দিয়ে Value পরিবর্তন

var score = 50;
```

score = 80;

console.log(score);
```

7. let দিয়ে Value পরিবর্তন

let score = 50;
```

score = 80;

console.log(score);
```

8. const দিয়ে Value পরিবর্তন করা যায় না

const score = 50;
```

score = 80;
```

এই code-এ error হবে, কারণ const variable reassign করা যায় না।

9. var, let এবং const-এর Basic Difference

Feature var let const
Value পরিবর্তন হ্যাঁ হ্যাঁ Reassign করা যায় না
Same scope-এ redeclare সম্ভব সম্ভব নয় সম্ভব নয়
Block scope না হ্যাঁ হ্যাঁ
Modern code-এ ব্যবহার পুরোনো code-এ বেশি হ্যাঁ হ্যাঁ

10. Variable Naming Rules

JavaScript variable-এর নাম দেওয়ার সময় কিছু নিয়ম মেনে চলতে হয়।

  • নামের মধ্যে space দেওয়া যাবে না
  • নাম number দিয়ে শুরু করা যাবে না
  • Letters, numbers, underscore এবং dollar sign ব্যবহার করা যায়
  • JavaScript-এর reserved keyword ব্যবহার করা যাবে না
  • Variable name case-sensitive
```

```
13. Camel Case কী?

JavaScript code-এ একাধিক শব্দের variable name লেখার সময় camelCase convention খুব বেশি ব্যবহার করা হয়। 

let firstName = "Munna";
```

let lastName = "Ahmed";

let phoneNumber = "01700000000";

```

21. Scope-এর Basic ধারণা

Scope বলতে বোঝায় কোনো variable কোথায় access করা যাবে।

let এবং const block-scoped। 

{
```

let name = "Munna";
const age = 20;

console.log(name);
console.log(age);
}
```

এই block-এর বাইরে একই variable সরাসরি access করা যাবে না।

22. var-এর Scope

var block scope-এর পরিবর্তে function scope অনুসরণ করে। এই আচরণের কারণে modern JavaScript-এ নতুন code লেখার সময় let বা const ব্যবহার করা সাধারণত বেশি সুবিধাজনক।
```

```
26. Common Mistakes

  • const variable-কে reassign করার চেষ্টা করা
  • Variable name-এর মধ্যে space ব্যবহার করা
  • Number দিয়ে variable name শুরু করা
  • Variable spelling ভুল করা
  • Uppercase এবং lowercase-এর পার্থক্য ভুলে যাওয়া
  • একই scope-এ let বা const redeclare করার চেষ্টা করা
  • পুরোনো var code দেখে তার scope behaviour না বোঝা
Beginner Tip: নতুন JavaScript code লেখার সময় সাধারণভাবে const দিয়ে শুরু করুন। Value পরে পরিবর্তন করতে হলে let ব্যবহার করুন। পুরোনো code বুঝতে var-এর behaviour-ও শিখে রাখুন।

28. Quick Revision

  • var → পুরোনো variable declaration keyword
  • let → value পরে পরিবর্তন করা যেতে পারে
  • const → variable reassign করা যায় না
  • Variable → data/value নিয়ে কাজ করতে সাহায্য করে
  • Variable name → case-sensitive
  • let ও const → block scoped

29. Frequently Asked Questions

JavaScript-এ let এবং const-এর মধ্যে পার্থক্য কী?

let variable-এর value পরে reassign করা যায়। const variable-কে পরে নতুন value দিয়ে reassign করা যায় না।

var কি এখনো ব্যবহার করা যায়?

হ্যাঁ, JavaScript-এ var এখনো language-এর অংশ। তবে নতুন code-এ এর scope behaviour-এর কারণে অনেক developer প্রয়োজন অনুযায়ী let ও const ব্যবহার করেন।

const variable-এর value কি কখনো পরিবর্তন করা যায়?

একটি primitive value-এর ক্ষেত্রে const variable-কে নতুন value দিয়ে reassign করা যায় না।

Beginner হিসেবে কোনটি আগে শিখব?

প্রথমে variable concept বুঝুন, তারপর const, let এবং var-এর পার্থক্য practice করুন।
```
