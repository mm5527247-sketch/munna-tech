JavaScript কী? Beginnerদের জন্য সম্পূর্ণ Guide

JavaScript হলো একটি জনপ্রিয় programming language যা website-কে interactive এবং dynamic করার জন্য ব্যবহার করা হয়।

HTML দিয়ে website-এর structure তৈরি করা হয়, CSS দিয়ে design করা হয়, আর JavaScript ব্যবহার করে website-এ বিভিন্ন ধরনের interaction এবং functionality যোগ করা যায়।

এই article-এ আপনি শিখবেন:
  • JavaScript কী
  • JavaScript কেন প্রয়োজন
  • HTML, CSS ও JavaScript-এর সম্পর্ক
  • JavaScript কোথায় লেখা হয়
  • Variable কী
  • Function কী
  • Event কী
  • Button click কাজ করানো
  • DOM-এর basic ধারণা
  • Beginner JavaScript project

1. JavaScript কী?

JavaScript হলো একটি programming language যার সাহায্যে website-এ বিভিন্ন ধরনের কাজ করানো যায়।

যেমন:

  • Button click করলে message দেখানো
  • Dark mode তৈরি করা
  • Form validation করা
  • Calculator তৈরি করা
  • Image slider তৈরি করা
  • Menu open এবং close করা
  • Dynamic content দেখানো

2. Web Development-এ JavaScript কেন দরকার?

শুধু HTML এবং CSS দিয়ে একটি সুন্দর static website তৈরি করা যায়। কিন্তু website-এ interaction যোগ করতে JavaScript গুরুত্বপূর্ণ।

উদাহরণ হিসেবে একটি button ধরুন। CSS দিয়ে button সুন্দর করা যায়, কিন্তু button চাপলে কোনো action করানোর জন্য JavaScript ব্যবহার করা যায়।

3. HTML, CSS এবং JavaScript-এর সম্পর্ক

HTML → Website-এর structure

CSS → Website-এর design

JavaScript → Website-এর behavior এবং interaction

এই তিনটি technology একসাথে ব্যবহার করেই modern frontend website তৈরি করা হয়।

4. JavaScript কোথায় লেখা যায়?

JavaScript HTML file-এর ভিতরে তিনভাবে ব্যবহার করা যায়:

  1. Inline JavaScript
  2. Internal JavaScript
  3. External JavaScript

5. Inline JavaScript

HTML element-এর ভিতরে সরাসরি JavaScript লেখা হলে সেটিকে Inline JavaScript বলা হয়। 

<button onclick="alert('Hello Munna Tech!')">
```

Click Me
```

6. Internal JavaScript

HTML file-এর মধ্যে <script> tag ব্যবহার করে JavaScript লেখা যায়। 

<script>
```

alert("Hello World!");
```

7. External JavaScript

বড় project-এর ক্ষেত্রে আলাদা JavaScript file তৈরি করা ভালো।

যেমন: 

<script src="script.js"></script>

এখানে script.js হলো external JavaScript file।

8. প্রথম JavaScript Code

JavaScript-এর সবচেয়ে সহজ example: 

console.log("Hello Munna Tech!");

Browser-এর Developer Console-এ এই message দেখা যাবে।

9. alert() কী?

Browser-এ একটি popup message দেখাতে alert() ব্যবহার করা যায়। 

alert("Welcome to Munna Tech!");

10. JavaScript Variable কী?

Variable হলো data রাখার জন্য একটি নামযুক্ত জায়গা। 

let name = "Munna";
```

console.log(name);
```

এখানে name variable-এর মধ্যে Munna value রাখা হয়েছে।

11. let এবং const

JavaScript-এ variable তৈরি করার জন্য let এবং const অনেক বেশি ব্যবহৃত হয়। 

let age = 20;
```

const country = "Bangladesh";
```

let variable-এর value পরে পরিবর্তন করা যায়। 

let score = 10;
```

score = 20;
```

const সাধারণভাবে এমন value-এর জন্য ব্যবহার করা হয় যেটি পরে reassign করা হবে না।

15. DOM কী?

DOM-এর পূর্ণরূপ হলো Document Object Model।

JavaScript DOM ব্যবহার করে HTML-এর element খুঁজে বের করতে, পরিবর্তন করতে এবং control করতে পারে। 

document.getElementById("title");

19. JavaScript শেখার সময় Common Mistakes

  • JavaScript file-এর নাম ভুল দেওয়া
  • script file-এর path ভুল দেওয়া
  • Variable-এর spelling ভুল করা
  • Bracket বন্ধ করতে ভুলে যাওয়া
  • HTML id এবং JavaScript id মিল না রাখা
  • Code কোথায় লিখতে হবে তা না বোঝা
Beginner Tip: JavaScript শেখার সময় শুধু tutorial পড়বেন না। প্রতিটি example নিজে টাইপ করে browser-এ run করুন। ছোট ছোট project বানালে শেখা অনেক সহজ হবে।

23. Frequently Asked Questions

JavaScript কি programming language?

হ্যাঁ। JavaScript একটি programming language এবং web development-এ ব্যাপকভাবে ব্যবহৃত হয়।

JavaScript শেখার আগে HTML ও CSS জানা দরকার?

Basic HTML এবং CSS জানা থাকলে JavaScript শেখা অনেক সহজ হয়।

JavaScript দিয়ে কি website বানানো যায়?

হ্যাঁ। JavaScript frontend website-এর interaction তৈরি করতে ব্যবহৃত হয়। এছাড়াও বিভিন্ন framework এবং runtime-এর মাধ্যমে আরও অনেক ধরনের application তৈরি করা যায়।

JavaScript শেখার জন্য কী software দরকার?

Beginner হিসেবে VS Code এবং একটি modern web browser দিয়েই JavaScript শেখা শুরু করা যায়।

24. উপসংহার

JavaScript হলো Web Development শেখার একটি গুরুত্বপূর্ণ অংশ। HTML এবং CSS-এর basic শেখার পর JavaScript শেখা শুরু করলে website-এ বিভিন্ন ধরনের interactive feature তৈরি করা সম্ভব।

নিয়মিত practice করুন এবং ছোট ছোট project তৈরি করুন। এভাবেই ধীরে ধীরে JavaScript-এর basic থেকে advanced level-এর দিকে এগিয়ে যেতে পারবেন।
