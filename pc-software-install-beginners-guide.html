PC-তে Software Install করার সঠিক নিয়ম | Windows 11 Beginner Guide

Windows PC ব্যবহার করার সময় বিভিন্ন কাজের জন্য Software Install করতে হয়। যেমন Web Development-এর জন্য VS Code, Browser, Image Editor বা অন্য প্রয়োজনীয় application।

কিন্তু Software install করার সময় ভুল website থেকে download, unwanted program install বা ভুল option select করার মতো সমস্যা হতে পারে।

এই guide-এ Windows PC-তে Software নিরাপদভাবে download, install এবং uninstall করার basic নিয়ম সহজ বাংলায় দেখানো হয়েছে।

``` এই Article-এ আপনি শিখবেন:
  • Software কী?
  • কোথা থেকে Software download করবেন
  • Official website চিনবেন কীভাবে
  • Installer file কী
  • Software install করার step-by-step নিয়ম
  • Express এবং Custom installation
  • Unwanted software এড়ানোর নিয়ম
  • Windows Security ব্যবহার
  • Software uninstall করার নিয়ম
```

1. Software কী?

Software হলো computer-এ নির্দিষ্ট কাজ করার জন্য ব্যবহৃত program বা application।

উদাহরণ হিসেবে:

  • Google Chrome — Web browsing
  • VS Code — Coding
  • Image editor — ছবি edit
  • Media player — Video বা audio চালানো

2. Software Download করার আগে কী করবেন?

কোনো software install করার আগে প্রথমে নিশ্চিত হন যে softwareটি আপনার প্রয়োজনের এবং আপনার Windows version-এর সঙ্গে compatible।

``` Check করুন:
  • Software-এর নাম
  • Official developer বা publisher
  • Windows compatibility
  • System requirements
  • Download source
```

3. সবসময় Official Source ব্যবহার করুন

Software download করার সময় সম্ভব হলে software-এর official website বা trusted distribution source ব্যবহার করুন।

``` সতর্কতা: Search result-এ প্রথম যে download button দেখবেন সেটিতে সরাসরি click করার বদলে website এবং publisher যাচাই করুন। Fake download button বা unwanted software-এর ঝুঁকি থাকতে পারে। ```

4. Official Website কীভাবে চিনবেন?

Official website যাচাই করার সময় কয়েকটি বিষয় লক্ষ্য করুন।

    ```
  • Developer বা company-এর নাম মিলছে কিনা
  • Website address সঠিক কিনা
  • Download page software publisher-এর website কিনা
  • অস্বাভাবিক popup বা misleading download button আছে কিনা
    • ```

কোনো website নিয়ে সন্দেহ হলে software download না করাই ভালো।

5. Installer File কী?

Windows software install করার জন্য অনেক সময় একটি installer file download করতে হয়।

Windows-এ installer file-এর extension হিসেবে .exe অথবা .msi দেখা যেতে পারে। 

Example:

setup.exe
installer.exe
program.msi
``` Important: শুধু .exe বা .msi extension দেখেই কোনো file safe ধরে নেবেন না। Download source এবং publisher অবশ্যই যাচাই করুন। ```

7. Step 1 — Software Download করুন

Software-এর trusted source থেকে installer download করুন।

Download শেষ হলে browser-এর Downloads folder-এ installer file পাওয়া যেতে পারে।

8. Step 2 — Installer Open করুন

Download করা installer file-এ double-click করলে installation process শুরু হতে পারে।

Windows permission চাইলে publisher এবং file source যাচাই করে তারপর সিদ্ধান্ত নিন।

``` খুব গুরুত্বপূর্ণ: Unknown publisher-এর installer হলে শুধু installation শুরু হয়েছে বলে Allow বা Yes চাপবেন না। আগে source যাচাই করুন। ```

9. Step 3 — License বা Terms পড়ুন

অনেক installer-এ software license বা terms দেখানো হয়। Installation চালিয়ে যাওয়ার আগে এগুলো দেখে নেওয়া ভালো।

10. Express বনাম Custom Installation

কিছু software installer-এ Express, Recommended অথবা Custom installation option থাকতে পারে।

```
Option সাধারণ অর্থ
Express / Recommended Software-এর recommended settings দিয়ে install
Custom Installation options নিজের মতো নির্বাচন করার সুযোগ
```

Custom option থাকলে installer কোন components এবং additional offers দিচ্ছে তা ভালোভাবে দেখে নিন।

11. Unwanted Software থেকে সতর্ক থাকুন

কিছু installer-এর সঙ্গে optional additional software, browser extension বা অন্য offer থাকতে পারে।

``` সতর্কতা: আপনি যে software install করতে চান না, সেটির checkbox বা optional offer থাকলে carefully review করুন। সব checkbox automatically select করে Continue করবেন না। ```

12. Installation Location

কিছু software install করার সময় installation folder নির্বাচন করার option থাকে।

Beginner হলে software-এর recommended/default location ব্যবহার করাই সাধারণত সহজ।

তবে storage কম থাকলে প্রয়োজন অনুযায়ী অন্য drive নির্বাচন করা যেতে পারে।

13. Install Button চাপুন

Settings review করার পরে Install button নির্বাচন করুন।

Installation শেষ হওয়া পর্যন্ত installer বন্ধ করবেন না।

Review
```

14. Finish করার পরে Software Open করুন

Installation complete হলে সাধারণত Finish, Close অথবা Launch option দেখা যেতে পারে।

Software open করে এটি ঠিকভাবে কাজ করছে কিনা পরীক্ষা করুন।

15. Desktop Shortcut দরকার কি?

কিছু installer desktop shortcut তৈরি করার option দেয়।

Shortcut প্রয়োজন হলে রাখতে পারেন। প্রয়োজন না হলে desktop clean রাখার জন্য shortcut না রাখলেও software ব্যবহার করতে সমস্যা হবে না।

16. Software Install করার পরে Update Check করুন

Installation শেষ হওয়ার পরে software-এর update option থাকলে সেটি check করা ভালো।

Updated software ব্যবহার করলে নতুন features, bug fixes এবং security improvements পাওয়া যেতে পারে।

17. Windows Security ব্যবহার করুন

Windows-এর built-in security features ব্যবহার করে downloaded files এবং installed software সম্পর্কে সতর্ক থাকা যায়।

``` Security Tip: শুধু antivirus আছে বলে unknown software install করা নিরাপদ ধরে নেবেন না। Download source এবং publisher যাচাই করা গুরুত্বপূর্ণ। ```

18. Software Install না হলে কী করবেন?

Installation failure-এর বিভিন্ন কারণ থাকতে পারে।

    ```
  • Softwareটি Windows version-এর সঙ্গে compatible নয়
  • Installer file damaged বা incomplete download
  • Storage space কম
  • Required system component missing
  • Permission-related সমস্যা
  • অন্য software-এর সঙ্গে conflict
    • ```

Error message থাকলে সেটি ভালোভাবে পড়ুন এবং software-এর official support/documentation থেকে solution খুঁজুন।

19. Software Uninstall করার নিয়ম

প্রয়োজন না থাকলে software uninstall করা যায়।

``` Windows Settings-এর মাধ্যমে: 
Settings
```

↓
Apps
↓
Installed apps
↓
Software নির্বাচন
↓
Uninstall

Windows version অনুযায়ী menu-এর নাম বা layout কিছুটা পরিবর্তিত হতে পারে।

20. Uninstall করার সময় সতর্কতা

কোনো software uninstall করার আগে নিশ্চিত হন যে softwareটি প্রয়োজনীয় system component নয়।

``` Don't: Random system files বা unknown program শুধু নাম দেখে uninstall করবেন না। ```

21. Software Install করার সময় Common Mistakes

    ```
  • Unknown website থেকে software download করা
  • Fake Download button-এ click করা
  • Publisher না দেখে installer চালানো
  • সব optional checkbox select করে দেওয়া
  • Software-এর system requirements না দেখা
  • Storage space check না করা
  • Unknown cracked বা modified installer ব্যবহার করা
    • ```

22. Beginnerদের জন্য Safe Installation Checklist

```
  1. Software-এর নাম যাচাই করুন
  2. Official/trusted source খুঁজুন
  3. Publisher যাচাই করুন
  4. System requirements দেখুন
  5. Installer download করুন
  6. Installation options carefully দেখুন
  7. Optional software থাকলে review করুন
  8. Install শেষ হওয়ার পর software test করুন
  9. প্রয়োজনে software update করুন
```

```
```

.exe file কি সবসময় safe?

না। .exe হলো একটি executable file type। File safe কিনা বুঝতে source, publisher এবং download context যাচাই করা দরকার।

```
```

Custom Installation কী?

```
```

Software install করার সময় সব checkbox select করব?

না। প্রতিটি option পড়ে বুঝে তারপর নির্বাচন করুন। Optional software বা unwanted offer থাকলে সেটি এড়িয়ে চলুন।

```
```

Windows 11-এ software uninstall কীভাবে করব?

```
