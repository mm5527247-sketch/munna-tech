HTML Form কী? সহজভাবে Form তৈরি করার সম্পূর্ণ গাইড

Website-এ User-এর কাছ থেকে তথ্য নেওয়ার জন্য HTML Form ব্যবহার করা হয়। যেমন Name, Email, Password, Phone Number, Message, Gender, Country ইত্যাদি তথ্য নেওয়ার জন্য Form প্রয়োজন হয়।

এই Beginner Guide-এ আমরা একদম সহজভাবে HTML Form তৈরি করা শিখব।

1. HTML Form কী?

HTML Form হলো এমন একটি অংশ যেখানে Website-এর Visitor বিভিন্ন তথ্য লিখে বা নির্বাচন করে Submit করতে পারে।

যেমন:

  • Contact Form
  • Login Form
  • Registration Form
  • Search Form
  • Feedback Form
  • Job Application Form

2. HTML Form তৈরি করতে কোন Tag ব্যবহার হয়?

HTML Form তৈরি করার জন্য প্রধানত <form> Tag ব্যবহার করা হয়।

<form>
  Form content এখানে থাকবে
</form>

3. HTML Input কী?

User-এর কাছ থেকে ছোট তথ্য নেওয়ার জন্য <input> Tag ব্যবহার করা হয়।

<input type="text">

এখানে type="text" ব্যবহার করার কারণে একটি সাধারণ text input তৈরি হবে।

4. Name নেওয়ার Form

<label>Your Name:</label>
<input type="text" placeholder="Enter your name">

placeholder User-কে input-এর ভিতরে একটি নির্দেশনা দেখায়।

5. Email নেওয়ার Form

<label>Email:</label>
<input type="email" placeholder="Enter your email">

type="email" ব্যবহার করলে Browser Email-এর format যাচাই করতে সাহায্য করে।

6. Password Field

<label>Password:</label>
<input type="password" placeholder="Enter password">

Password field-এ User-এর লেখা সাধারণত লুকানো অবস্থায় দেখা যায়।

7. Number Input

<label>Age:</label>
<input type="number" placeholder="Enter your age">

8. Radio Button

একাধিক Option থেকে সাধারণত একটি Option নির্বাচন করার জন্য Radio Button ব্যবহার করা হয়।

<p>Gender:</p>

<input type="radio" name="gender" value="male"> Male
<input type="radio" name="gender" value="female"> Female
Tip: একই group-এর Radio Button-এর জন্য একই name ব্যবহার করা গুরুত্বপূর্ণ।

9. Checkbox

একাধিক Option নির্বাচন করার জন্য Checkbox ব্যবহার করা হয়।

<p>Your Skills:</p>

<input type="checkbox" name="skill" value="html"> HTML
<input type="checkbox" name="skill" value="css"> CSS
<input type="checkbox" name="skill" value="javascript"> JavaScript

10. Select Dropdown

অনেকগুলো Option-এর মধ্যে থেকে একটি নির্বাচন করার জন্য Select Dropdown ব্যবহার করা যায়।

<label>Choose Country:</label>
<select>
  <option>Bangladesh</option>
  <option>India</option>
  <option>Pakistan</option>
  <option>Nepal</option>
</select>

11. Textarea

বড় আকারের Text বা Message নেওয়ার জন্য <textarea> ব্যবহার করা হয়।

<label>Your Message:</label>
<textarea rows="5" placeholder="Write your message"></textarea>

12. Submit Button

Form Submit করার জন্য Button ব্যবহার করা হয়।

<button type="submit">Submit</button>

13. একটি সম্পূর্ণ HTML Form

এখন আমরা Name, Email, Password, Gender, Skills, Country এবং Message ব্যবহার করে একটি সম্পূর্ণ Form তৈরি করব।

<form>

  <label>Name:</label><br>
  <input type="text" placeholder="Enter your name"><br><br>

  <label>Email:</label><br>
  <input type="email" placeholder="Enter your email"><br><br>

  <label>Password:</label><br>
  <input type="password" placeholder="Enter password"><br><br>

  <p>Gender:</p>
  <input type="radio" name="gender"> Male
  <input type="radio" name="gender"> Female

  <p>Skills:</p>
  <input type="checkbox"> HTML
  <input type="checkbox"> CSS
  <input type="checkbox"> JavaScript

  <label>Country:</label><br>
  <select>
    <option>Bangladesh</option>
    <option>India</option>
    <option>Pakistan</option>
  </select><br><br>

  <label>Message:</label><br>
  <textarea rows="5" placeholder="Write your message"></textarea><br><br>

  <button type="submit">Submit</button>

</form>

14. Form-এর ভিতরে Label কেন ব্যবহার করব?

<label> ব্যবহার করলে Form-এর কোন Field-এ কী তথ্য দিতে হবে তা User সহজে বুঝতে পারে।

<label for="email">Email</label>
<input type="email" id="email">

এখানে for এবং id একই রাখা হয়েছে। এটি Accessibility-এর জন্যও ভালো practice।

15. Required Field

কোনো Field অবশ্যই পূরণ করতে হবে এমন করতে required attribute ব্যবহার করা যায়।

<input type="text" required>

User Field পূরণ না করে Submit করলে Browser সতর্ক করবে।

16. Email Validation

Email Field-এর জন্য type="email" ব্যবহার করা ভালো।

<input type="email" required>

17. Contact Form-এর একটি সহজ Example

Important: উপরের Form-টি শুধু Demo হিসেবে কাজ করবে। বাস্তবে User-এর তথ্য Email বা Server-এ পাঠাতে Backend বা কোনো Form Service প্রয়োজন হতে পারে।

18. HTML Form-এর Common Mistakes

  • Form বন্ধ করার জন্য </form> দিতে ভুল করা
  • Radio Button-এর name ভুল দেওয়া
  • Email-এর জন্য text input ব্যবহার করা
  • Required Field-এ required না দেওয়া
  • Label ব্যবহার না করা
  • Input-এর placeholder ভুল লেখা
  • Form data কোথায় যাবে তা নির্ধারণ না করা

19. Beginner Practice Task

এখন নিজে একটি Registration Form তৈরি করার চেষ্টা করুন।

  1. Name Field তৈরি করুন
  2. Email Field তৈরি করুন
  3. Password Field তৈরি করুন
  4. Gender-এর জন্য Radio Button দিন
  5. Skills-এর জন্য Checkbox দিন
  6. Country-এর জন্য Dropdown দিন
  7. Message-এর জন্য Textarea দিন
  8. Submit Button দিন
Practice Tip: প্রথমে দেখে দেখে Code লিখুন। পরে Code না দেখে নিজে আবার তৈরি করার চেষ্টা করুন।

20. HTML Form শেখার পর কী শিখবেন?

HTML Form শেখার পর CSS দিয়ে Form সুন্দরভাবে Design করা শিখতে পারেন। এরপর JavaScript ব্যবহার করে Form Validation এবং Interactive Form তৈরি করা যায়।

Frequently Asked Questions (FAQ)

HTML Form কী?

Website Visitor-এর কাছ থেকে তথ্য নেওয়ার জন্য ব্যবহৃত HTML-এর একটি অংশকে HTML Form বলা হয়।

HTML Form-এর প্রধান Tag কোনটি?

HTML Form তৈরি করার প্রধান Tag হলো <form>।

Input Tag কী কাজে লাগে?

User-এর কাছ থেকে বিভিন্ন ধরনের ছোট তথ্য নেওয়ার জন্য <input> Tag ব্যবহার করা হয়।

Radio Button কী?

সাধারণত একাধিক Option থেকে একটি Option নির্বাচন করার জন্য Radio Button ব্যবহার করা হয়।

Checkbox কী?

একাধিক Option নির্বাচন করার জন্য Checkbox ব্যবহার করা হয়।

Textarea কী?

বড় Text বা Message নেওয়ার জন্য Textarea ব্যবহার করা হয়।

Conclusion

HTML Form Web Development-এর একটি গুরুত্বপূর্ণ বিষয়। Form-এর মাধ্যমে User-এর কাছ থেকে Name, Email, Password, Message এবং অন্যান্য তথ্য নেওয়া যায়।

আপনি যদি Web Development শিখতে চান, তাহলে HTML Form ভালোভাবে Practice করা খুবই গুরুত্বপূর্ণ। এরপর CSS এবং JavaScript ব্যবহার করে আরও Professional Form তৈরি করতে পারবেন।
