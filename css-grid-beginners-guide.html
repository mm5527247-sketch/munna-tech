CSS Grid কী? Beginnerদের জন্য সম্পূর্ণ Guide

CSS Grid হলো modern website layout তৈরি করার একটি powerful CSS system। এর মাধ্যমে খুব সহজে rows এবং columns ব্যবহার করে website-এর বিভিন্ন section, card, gallery এবং responsive layout তৈরি করা যায়।

এই article-এ আপনি শিখবেন:
  • CSS Grid কী
  • Grid Container ও Grid Item
  • Columns ও Rows
  • grid-template-columns
  • grid-template-rows
  • gap
  • repeat()
  • grid-column ও grid-row
  • Responsive Grid
  • Card Grid Project

1. CSS Grid কী?

CSS Grid হলো CSS-এর একটি layout system যার সাহায্যে website-এর content কে rows এবং columns-এর মাধ্যমে সাজানো যায়।

বিশেষ করে দুই-dimensional layout তৈরি করার জন্য CSS Grid খুবই কার্যকর। অর্থাৎ একই সঙ্গে row এবং column নিয়ন্ত্রণ করা যায়।

2. CSS Grid কেন ব্যবহার করবেন?

  • Website layout সহজে তৈরি করা যায়
  • Card layout তৈরি করা যায়
  • Image gallery তৈরি করা যায়
  • Responsive design করা যায়
  • কম CSS code-এ সুন্দর layout তৈরি করা যায়
  • Desktop ও mobile layout সহজে নিয়ন্ত্রণ করা যায়

3. display: grid কী?

কোনো HTML element-কে Grid Container বানানোর জন্য ব্যবহার করতে হয়: 

.container {
```

display: grid;
}
```

এরপর container-এর ভিতরের elements-গুলো Grid Items হিসেবে কাজ করবে।

4. Grid Container এবং Grid Item

যে parent element-এর মধ্যে display: grid; দেওয়া হয় সেটি হলো Grid Container।

আর সেই container-এর ভিতরের child elements হলো Grid Items।

5. Grid Columns তৈরি করা

Columns তৈরি করতে সবচেয়ে বেশি ব্যবহার করা property হলো grid-template-columns। 

.container {
```

display: grid;
grid-template-columns: 1fr 1fr 1fr;
}
```

এখানে তিনটি সমান column তৈরি হবে।

6. 2টি Column তৈরি

.container {
```

display: grid;
grid-template-columns: 1fr 1fr;
}
```

এখানে দুইটি সমান column তৈরি হবে।

7. 3টি Column তৈরি

.container {
```

display: grid;
grid-template-columns: 1fr 1fr 1fr;
}
```

8. grid-template-rows

Grid-এর row-এর size নিয়ন্ত্রণ করতে grid-template-rows ব্যবহার করা হয়। 

.container {
```

display: grid;
grid-template-rows: 100px 200px;
}
```

9. gap কী?

Grid item-এর মধ্যে ফাঁকা জায়গা তৈরি করতে gap ব্যবহার করা হয়। 

.container {
```

display: grid;
gap: 20px;
}
```

এখানে প্রতিটি row এবং column-এর মধ্যে 20px gap থাকবে।

10. Column এবং Row আলাদা Gap

.container {
```

display: grid;
column-gap: 30px;
row-gap: 20px;
}
```

11. repeat() Function

একই ধরনের column বারবার লেখার পরিবর্তে repeat() ব্যবহার করা যায়। 

.container {
```

display: grid;
grid-template-columns: repeat(3, 1fr);
}
```

এটি মূলত এই code-এর মতো: 

grid-template-columns: 1fr 1fr 1fr;

12. grid-column কী?

কোনো Grid Item কতগুলো column জুড়ে থাকবে তা নির্ধারণ করতে grid-column ব্যবহার করা যায়। 

.item1 {
```

grid-column: 1 / 3;
}
```

এর ফলে itemটি প্রথম column থেকে তৃতীয় column-এর আগে পর্যন্ত জায়গা নেবে।

13. grid-row কী?

কোনো item কতগুলো row জুড়ে থাকবে তা নির্ধারণ করতে grid-row ব্যবহার করা যায়। 

.item1 {
```

grid-row: 1 / 3;
}
```

14. একটি Item দুইটি Column জুড়ে রাখা

.featured {
```

grid-column: 1 / 3;
}
```

এটি blog card, featured post বা বড় image section তৈরিতে ব্যবহার করা যায়।

17. Responsive CSS Grid

Mobile, tablet এবং desktop—সব device-এ Grid responsive করার জন্য auto-fit এবং minmax() খুব useful। 

.grid {
```

display: grid;
grid-template-columns:
repeat(auto-fit, minmax(200px, 1fr));
gap: 20px;
}
```

এই technique ব্যবহার করলে screen ছোট হলে column সংখ্যা কমে যাবে এবং screen বড় হলে বেশি column দেখা যেতে পারে।

20. CSS Grid-এর Common Mistakes

  • display: grid; দিতে ভুল করা
  • grid-template-columns ভুল লেখা
  • Grid container এবং Grid item-এর পার্থক্য না বোঝা
  • Mobile responsive design না করা
  • অতিরিক্ত fixed width ব্যবহার করা
  • gap ব্যবহার না করে অনেক margin দেওয়া
Beginner Tip: প্রথমে display: grid, তারপর grid-template-columns এবং gap ভালোভাবে practice করুন। এরপর grid-column, grid-row এবং responsive Grid শিখুন।

22. Quick Revision

  • display: grid; → Grid চালু করে
  • grid-template-columns → Column তৈরি করে
  • grid-template-rows → Row তৈরি করে
  • gap → Item-এর মধ্যে space দেয়
  • repeat() → একই pattern বারবার ব্যবহার করে
  • grid-column → Column-এর জায়গা নিয়ন্ত্রণ করে
  • grid-row → Row-এর জায়গা নিয়ন্ত্রণ করে
  • minmax() → Responsive size নিয়ন্ত্রণে সাহায্য করে

23. Frequently Asked Questions

CSS Grid কি beginners-এর জন্য কঠিন?

না। Basic property যেমন display, columns, rows এবং gap দিয়ে শুরু করলে ধীরে ধীরে সহজ হয়ে যায়।

CSS Grid এবং Flexbox-এর মধ্যে পার্থক্য কী?

Flexbox সাধারণত এক-dimensional layout-এর জন্য বেশি ব্যবহৃত হয়। CSS Grid rows এবং columns মিলিয়ে two-dimensional layout তৈরি করতে পারে।

Responsive website-এ CSS Grid ব্যবহার করা যায়?

অবশ্যই। auto-fit, minmax() এবং flexible units ব্যবহার করে responsive Grid তৈরি করা যায়।
