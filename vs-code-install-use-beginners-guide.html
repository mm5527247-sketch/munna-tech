VS Code কী? Install ও ব্যবহার করার নিয়ম | Beginner Guide

আপনি যদি Web Development শিখতে চান, তাহলে একটি ভালো code editor ব্যবহার করা খুবই গুরুত্বপূর্ণ। Visual Studio Code, সংক্ষেপে VS Code, HTML, CSS এবং JavaScript শেখার জন্য বহুল ব্যবহৃত একটি source-code editor।

এই guide-এ Windows PC-তে VS Code install করা থেকে শুরু করে project folder খোলা, HTML file তৈরি, extensions ব্যবহার, Live Server এবং beginner coding workflow সম্পর্কে সহজভাবে জানবেন।

এই article-এ আপনি শিখবেন:
  • VS Code কী
  • VS Code কেন ব্যবহার করবেন
  • Windows PC-তে VS Code install করার basic steps
  • Project folder খোলা
  • HTML file তৈরি করা
  • CSS ও JavaScript file তৈরি করা
  • Extensions কী
  • Live Server কী
  • Useful keyboard shortcuts
  • Beginnerদের common problems

1. VS Code কী?

VS Code হলো Microsoft-এর তৈরি একটি source-code editor। এতে বিভিন্ন programming এবং web development project-এর code লেখা ও manage করা যায়।

HTML, CSS, JavaScript ছাড়াও অনেক programming language এবং development workflow-এর জন্য VS Code ব্যবহার করা যায়।

2. Web Development-এর জন্য VS Code কেন ব্যবহার করবেন?

Web Development শেখার সময় একই project-এর মধ্যে HTML, CSS, JavaScript এবং অন্যান্য file নিয়ে কাজ করতে হয়। VS Code এই কাজগুলোকে একটি জায়গায় organize করতে সাহায্য করে।

  • Code লেখা সহজ
  • Syntax highlighting আছে
  • Auto completion পাওয়া যায়
  • Multiple file manage করা যায়
  • Extensions ব্যবহার করা যায়
  • Integrated terminal রয়েছে
  • Git ও GitHub workflow-এর সাথে ব্যবহার করা যায়

3. VS Code Install করার আগে কী লাগবে?

Windows PC-তে VS Code ব্যবহার করার জন্য সাধারণত একটি compatible Windows computer এবং internet connection প্রয়োজন।

Installation-এর জন্য Microsoft-এর official website থেকে installer নেওয়া ভালো।

4. Windows PC-তে VS Code Install করার নিয়ম

Step 1 — Official Download Page খুলুন

Browser খুলে Visual Studio Code-এর official download page-এ যান।

Step 2 — Windows Version নির্বাচন করুন

আপনার Windows PC-এর জন্য উপযুক্ত installer download করুন।

Step 3 — Installer চালু করুন

Download করা installer file খুলে installation process শুরু করুন।

Step 4 — Setup Complete করুন

Installer-এর নির্দেশনা অনুসরণ করে installation শেষ করুন।

Tip: Software download করার সময় official source ব্যবহার করার অভ্যাস করুন। এতে ভুল বা modified installer ব্যবহারের ঝুঁকি কমে।

5. VS Code Open করার পর কী দেখবেন?

VS Code খুললে সাধারণত একটি welcome/start screen দেখা যেতে পারে। এখান থেকে নতুন file তৈরি বা existing project folder open করা যায়।

6. Project Folder কী?

আপনার website-এর HTML, CSS, JavaScript এবং image files একসাথে রাখার জন্য একটি project folder তৈরি করা ভালো।

উদাহরণ:

my-website/
```

│
├── index.html
├── style.css
├── script.js
└── images/
```

7. VS Code-এ Project Folder Open করার নিয়ম

Step 1

VS Code খুলুন।

Step 2

File → Open Folder নির্বাচন করুন।

Step 3

আপনার website-এর project folder নির্বাচন করুন।

Step 4

Folder open হলে Explorer panel-এ আপনার files দেখা যাবে।

8. প্রথম HTML File তৈরি করুন

Project folder-এর ভিতরে একটি নতুন file তৈরি করে নাম দিন: 

index.html

এরপর নিচের basic HTML code লিখতে পারেন: 

<!DOCTYPE html>
```









My Website






Hello World




I am learning Web Development.
```

9. CSS File তৈরি করুন

Project folder-এর ভিতরে: 

style.css

HTML file-এর সঙ্গে CSS যুক্ত করতে: 

<link rel="stylesheet" href="style.css">

10. JavaScript File তৈরি করুন

Project folder-এর ভিতরে: 

script.js

HTML-এর সঙ্গে JavaScript যুক্ত করতে: 

<script src="script.js"></script>

11. VS Code-এর Explorer কী?

VS Code-এর Explorer panel থেকে project-এর files এবং folders দেখা, তৈরি, rename এবং manage করা যায়।

আপনার project বড় হলে এই Explorer panel code organization-এর জন্য খুব গুরুত্বপূর্ণ হয়ে ওঠে।

12. VS Code Extensions কী?

Extensions হলো VS Code-এর অতিরিক্ত features যোগ করার tools। প্রয়োজন অনুযায়ী extension install করে editor-এর functionality বাড়ানো যায়।

তবে Beginner হিসেবে প্রয়োজনের বেশি extension install করার দরকার নেই।

13. Live Server কী?

Live Server ধরনের extension ব্যবহার করে local website browser-এ চালানো এবং file পরিবর্তনের পর দ্রুত preview দেখা সহজ হতে পারে।

Beginner HTML/CSS practice-এর সময় এটি বেশ সুবিধাজনক।

14. Browser-এ HTML File চালানোর সহজ উপায়

Live Server ব্যবহার না করলেও HTML file save করে সেটি browser-এ open করা যায়।

উদাহরণ: 

index.html

File-টির ওপর double-click করলে default browser-এ page open হতে পারে।

17. Auto Save ব্যবহার করবেন?

VS Code-এ Auto Save option ব্যবহার করা যায়। এতে file পরিবর্তন করার পর automatically save হতে পারে।

Beginner হিসেবে manual save-এর জন্য Ctrl + S ব্যবহার করার অভ্যাস করাও ভালো।

20. Integrated Terminal কী?

VS Code-এর ভিতরেই terminal ব্যবহার করা যায়। এখান থেকে project folder-এর command চালানো, Git ব্যবহার করা এবং বিভিন্ন development tool পরিচালনা করা যায়।

Beginner হিসেবে প্রথমে terminal-এর basic command ধীরে ধীরে শেখা যথেষ্ট।

21. Git এবং GitHub-এর সঙ্গে VS Code

Git install করা থাকলে VS Code-এর Source Control section থেকে project-এর Git changes দেখা এবং manage করা যায়।

GitHub-এর সঙ্গে project connect করলে code repository online-এ রাখা এবং update করা সহজ হয়।

  11. Project শেষ হলে GitHub-এ upload করুন

23. Common Problems ও Solutions

Problem: File Not Found

File-এর নাম এবং extension ঠিক আছে কিনা দেখুন। যেমন index.html এবং index.html.txt এক নয়।

Problem: CSS কাজ করছে না

HTML-এর stylesheet path পরীক্ষা করুন: 

<link rel="stylesheet" href="style.css">

Problem: JavaScript কাজ করছে না

JavaScript file-এর path এবং browser console-এর error check করুন।

Problem: Changes দেখা যাচ্ছে না

File save করুন এবং browser refresh করুন। প্রয়োজনে browser cache-এর বিষয়টিও পরীক্ষা করতে পারেন।

24. Beginnerদের Common Mistakes

  • File extension ভুল দেওয়া
  • Project folder-এর বাইরে file রাখা
  • CSS path ভুল লেখা
  • JavaScript path ভুল লেখা
  • File save না করা
  • অপ্রয়োজনীয় অনেক extension install করা
  • Code error দেখেও browser console না দেখা
Beginner Tip: প্রথমে শুধু HTML, CSS এবং JavaScript নিয়ে practice করুন। অনেক extension একসাথে install না করে প্রয়োজন অনুযায়ী ধীরে ধীরে নতুন tool ব্যবহার করুন।

27. Frequently Asked Questions

VS Code কি free?

VS Code বিনামূল্যে ব্যবহার করা যায়।

VS Code দিয়ে HTML শেখা যাবে?

হ্যাঁ। HTML, CSS এবং JavaScript practice করার জন্য VS Code ব্যবহার করা যায়।

VS Code কি শুধু Web Development-এর জন্য?

না। বিভিন্ন programming language এবং development project-এর জন্য VS Code ব্যবহার করা যায়।

Live Server কি অবশ্যই দরকার?

না। HTML file সরাসরি browser-এও open করা যায়। তবে Live Server local development workflow সহজ করতে পারে।

Beginner হিসেবে কোন file আগে তৈরি করব?

সাধারণ website project-এর জন্য প্রথমে index.html তৈরি করে HTML structure লেখা শুরু করতে পারেন।

28. উপসংহার

VS Code Web Development শেখার জন্য একটি গুরুত্বপূর্ণ coding tool। এটি ব্যবহার করে HTML, CSS এবং JavaScript-এর project সহজে organize এবং edit করা যায়।

Beginner হিসেবে প্রথমে একটি project folder তৈরি করুন, index.html, style.css এবং script.js দিয়ে practice শুরু করুন।

এরপর ধীরে ধীরে Extensions, Live Server, Git এবং GitHub-এর মতো tools শেখার দিকে এগিয়ে যেতে পারেন।
