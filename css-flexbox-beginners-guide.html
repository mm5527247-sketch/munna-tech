CSS Flexbox কী? Beginnerদের জন্য সম্পূর্ণ Guide

CSS Flexbox হলো website-এর elementগুলোকে সুন্দরভাবে arrange এবং align করার একটি powerful CSS layout system।

Navbar, card, button group, profile section এবং responsive layout তৈরি করতে Flexbox খুবই কাজে লাগে।

💡 Beginner Tip: Flexbox শেখার সময় শুধু code মুখস্থ না করে প্রতিটি property পরিবর্তন করে browser-এ result দেখুন।

1. CSS Flexbox কী?

Flexbox-এর পুরো নাম হলো Flexible Box Layout। এটি একটি container-এর ভিতরের elements-কে row বা column আকারে সাজাতে সাহায্য করে।

Flexbox ব্যবহার করার জন্য প্রথমে parent element-এ লিখতে হয়: 

.container {
    display: flex;
}

এখন container-এর direct child elements flex items হিসেবে কাজ করবে।

2. display: flex

Flexbox শুরু করার সবচেয়ে গুরুত্বপূর্ণ property হলো: 

.container {
    display: flex;
}

ধরুন HTML: 

<div class="container">
    <div>Box 1</div>
    <div>Box 2</div>
    <div>Box 3</div>
</div>

Parent-এ display: flex দিলে child boxes সাধারণত পাশাপাশি বসবে।

3. Main Axis ও Cross Axis

Flexbox বুঝতে Main Axis এবং Cross Axis বোঝা গুরুত্বপূর্ণ।

Defaultভাবে:

  • Main Axis = Horizontal
  • Cross Axis = Vertical

এই axis-এর উপর ভিত্তি করে justify-content এবং align-items কাজ করে।

4. flex-direction

Flex items কোন direction-এ থাকবে তা flex-direction দিয়ে নির্ধারণ করা যায়।

Row

.container {
    display: flex;
    flex-direction: row;
}

এটি default value এবং items পাশাপাশি থাকবে।

Column

.container {
    display: flex;
    flex-direction: column;
}

এতে items উপর থেকে নিচে সাজানো হবে।

Row Reverse

.container {
    display: flex;
    flex-direction: row-reverse;
}

Column Reverse

.container {
    display: flex;
    flex-direction: column-reverse;
}

5. justify-content

Main Axis বরাবর items-এর অবস্থান নিয়ন্ত্রণ করতে justify-content ব্যবহার করা হয়।

Center

.container {
    display: flex;
    justify-content: center;
}

Space Between

.container {
    display: flex;
    justify-content: space-between;
}

Space Around

.container {
    display: flex;
    justify-content: space-around;
}

Space Evenly

.container {
    display: flex;
    justify-content: space-evenly;
}

আরও ব্যবহারযোগ্য value:

  • flex-start
  • flex-end
  • center
  • space-between
  • space-around
  • space-evenly

6. align-items

Cross Axis বরাবর items align করার জন্য align-items ব্যবহার করা হয়। 

.container {
    display: flex;
    align-items: center;
}

Common value:

  • stretch
  • flex-start
  • flex-end
  • center
  • baseline

7. Horizontal ও Vertical Center

একটি element-কে একই সাথে horizontal এবং vertical center করার সবচেয়ে সহজ উপায়গুলোর একটি হলো: 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
Center Box

8. gap

Flex items-এর মধ্যে সমান দূরত্ব দিতে gap ব্যবহার করা যায়। 

.container {
    display: flex;
    gap: 20px;
}

এটি margin দিয়ে প্রতিটি item আলাদা আলাদা করার চেয়ে অনেক সহজ।

9. flex-wrap

এক লাইনে জায়গা না হলে items যেন পরের লাইনে চলে যায়, তার জন্য flex-wrap ব্যবহার করা হয়। 

.container {
    display: flex;
    flex-wrap: wrap;
}

Responsive card layout তৈরিতে এটি খুব গুরুত্বপূর্ণ।

11. flex property

Flex item-এর available space কীভাবে ভাগ হবে তা নিয়ন্ত্রণ করতে flex property ব্যবহার করা যায়। 

.item {
    flex: 1;
}

যদি তিনটি item-এ flex: 1 থাকে, তাহলে তারা available space প্রায় সমানভাবে ভাগ করতে পারে। 

.item1 {
    flex: 1;
}

.item2 {
    flex: 2;
}

এখানে দ্বিতীয় item প্রথমটির তুলনায় বেশি space নিতে পারে।

12. align-self

Parent-এর সব item-এর বদলে নির্দিষ্ট একটি item আলাদাভাবে align করতে align-self ব্যবহার করা যায়। 

.special-item {
    align-self: flex-end;
}

13. order

Flex item-এর visual order পরিবর্তন করতে order ব্যবহার করা যায়। 

.first {
    order: 2;
}

.second {
    order: 1;
}

এখানে HTML-এর order একই থাকলেও screen-এ display order পরিবর্তিত হতে পারে।

14. Flexbox দিয়ে Navbar তৈরি

Flexbox দিয়ে professional navbar তৈরি করা সহজ। 

<nav class="navbar">

    <div class="logo">Munna Tech</div>

    <div class="menu">
        <a href="#">Home</a>
        <a href="#">Tutorials</a>
        <a href="#">PC Tips</a>
        <a href="#">Contact</a>
    </div>

</nav>

CSS:

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 15px 30px;
}

.menu {
    display: flex;
    gap: 20px;
}

15. Flexbox দিয়ে Card Layout

একাধিক card পাশাপাশি রাখার জন্য Flexbox খুব জনপ্রিয়। 

.cards {
    display: flex;
    gap: 20px;
    flex-wrap: wrap;
}

.card {
    flex: 1 1 250px;
}

এভাবে screen ছোট হলে cardগুলো পরের লাইনে যেতে পারে।

16. Responsive Flexbox

Mobile screen-এর জন্য Flexbox direction পরিবর্তন করা যায়। 

.container {
    display: flex;
    gap: 20px;
}

@media (max-width: 600px) {

    .container {
        flex-direction: column;
    }

}

Desktop-এ items পাশাপাশি এবং mobile-এ উপর-নিচে রাখা যাবে।

18. Flexbox-এর Common Mistakes

  • Parent element-এ display: flex না দেওয়া
  • justify-content ও align-items-এর কাজ গুলিয়ে ফেলা
  • flex-direction পরিবর্তন করার পর axis না বোঝা
  • Mobile-এর জন্য flex-wrap ব্যবহার না করা
  • অতিরিক্ত fixed width ব্যবহার করা
  • gap-এর বদলে অপ্রয়োজনীয় margin ব্যবহার করা

  • Title

21. FAQ

CSS Flexbox কী?

Flexbox হলো CSS-এর একটি layout system যা elements-কে row বা column আকারে সাজানো এবং align করতে সাহায্য করে।

display: flex কী করে?

Parent element-কে flex container বানায় এবং তার direct children-কে flex items হিসেবে পরিচালনা করে।

justify-content কী?

Flex container-এর Main Axis বরাবর items-এর alignment নিয়ন্ত্রণ করে।

align-items কী?

Cross Axis বরাবর flex items-এর alignment নিয়ন্ত্রণ করে।

gap কী?

Flex items-এর মধ্যে নির্দিষ্ট দূরত্ব তৈরি করার সহজ property হলো gap।

Flexbox কি responsive website-এ ব্যবহার করা যায়?

হ্যাঁ। flex-wrap, flexible sizing এবং media query ব্যবহার করে responsive layout তৈরি করা যায়।
