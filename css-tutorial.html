CSS TUTORIAL

CSS শেখা শুরু করুন 🎨

Beginnerদের জন্য সহজভাবে CSS শেখার সম্পূর্ণ basic tutorial।

Lesson 1: CSS কী?

CSS-এর পূর্ণরূপ হলো Cascading Style Sheets। Website-এর design, color, size, spacing এবং layout পরিবর্তন করতে CSS ব্যবহার করা হয়। 

p {
    color: blue;
}

Lesson 2: CSS Syntax

CSS-এর সাধারণ structure হলো selector, property এবং value। 

h1 {
    color: red;
    font-size: 30px;
}

এখানে h1 হলো selector, color ও font-size হলো property।

Lesson 3: CSS Colors

CSS দিয়ে text এবং background-এর color পরিবর্তন করা যায়। 

h1 {
    color: blue;
}

body {
    background-color: lightgray;
}

Lesson 4: CSS Font Size

font-size property দিয়ে লেখার size পরিবর্তন করা হয়। 

h1 {
    font-size: 40px;
}

p {
    font-size: 18px;
}

Lesson 5: CSS Text Alignment

Text-এর অবস্থান পরিবর্তন করতে text-align ব্যবহার করা হয়। 

h1 {
    text-align: center;
}

p {
    text-align: left;
}

Lesson 6: CSS Background

Element-এর background color পরিবর্তন করা যায়। 

.box {
    background-color: black;
    color: white;
}

Lesson 7: CSS Border

Element-এর চারপাশে border তৈরি করতে border property ব্যবহার করা হয়। 

.box {
    border: 2px solid black;
}

Lesson 8: CSS Border Radius

Box-এর corner গোল করতে border-radius ব্যবহার করা হয়। 

.box {
    border-radius: 10px;
}

Lesson 9: CSS Padding

Element-এর ভিতরের space নিয়ন্ত্রণ করতে padding ব্যবহার করা হয়। 

.box {
    padding: 20px;
}

Lesson 10: CSS Margin

একটি element থেকে অন্য element-এর বাইরের distance নিয়ন্ত্রণ করতে margin ব্যবহার করা হয়। 

.box {
    margin: 20px;
}

Lesson 11: CSS Width & Height

Element-এর width এবং height নির্ধারণ করা যায়। 

.box {
    width: 300px;
    height: 150px;
}

Lesson 12: CSS Fonts

CSS দিয়ে font family এবং font weight পরিবর্তন করা যায়। 

body {
    font-family: Arial, sans-serif;
}

h1 {
    font-weight: bold;
}

Lesson 13: CSS Box Shadow

Box-এর চারপাশে shadow তৈরি করতে box-shadow ব্যবহার করা হয়। 

.card {
    box-shadow: 0 5px 20px rgba(0,0,0,0.15);
}

Lesson 14: CSS Display

Element কীভাবে display হবে তা নিয়ন্ত্রণ করতে display property ব্যবহার করা হয়। 

.box {
    display: block;
}

.button {
    display: inline-block;
}

Lesson 15: CSS Flexbox

Flexbox ব্যবহার করে element-গুলোকে সহজে row বা column আকারে সাজানো যায়। 

.container {
    display: flex;
    gap: 20px;
}

Lesson 16: CSS Justify Content

Flexbox-এর ভিতরের element-এর horizontal position নিয়ন্ত্রণ করতে justify-content ব্যবহার করা হয়। 

.container {
    display: flex;
    justify-content: center;
}

Lesson 17: CSS Align Items

Flexbox-এর element vertical direction-এ align করতে align-items ব্যবহার করা হয়। 

.container {
    display: flex;
    align-items: center;
}

Lesson 18: CSS Hover

Mouse কোনো element-এর উপর নিলে তার style পরিবর্তন করতে :hover ব্যবহার করা হয়। 

button:hover {
    transform: translateY(-2px);
}

Lesson 19: CSS Responsive Design

বিভিন্ন screen size-এর জন্য website responsive করতে media query ব্যবহার করা হয়। 

@media (max-width: 600px) {

    h1 {
        font-size: 30px;
    }

}

Lesson 20: Complete CSS Example

এখন HTML element-এর সাথে CSS একসাথে ব্যবহার করি। 

.card {
    width: 300px;
    padding: 20px;
    background-color: white;
    border-radius: 15px;
    box-shadow: 0 5px 20px rgba(0,0,0,0.1);
}

.card h2 {
    color: blue;
}

.card p {
    color: gray;
}

🎉 Congratulations! আপনি CSS-এর গুরুত্বপূর্ণ basic concepts শেষ করেছেন। এখন JavaScript শিখলে website-এ interaction এবং functionality যোগ করতে পারবেন।
