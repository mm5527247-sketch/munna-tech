JavaScript Function কী? Beginnerদের জন্য সম্পূর্ণ Guide

JavaScript শেখার সময় Function একটি অত্যন্ত গুরুত্বপূর্ণ concept। Function ব্যবহার করে একটি নির্দিষ্ট কাজের code এক জায়গায় রাখা যায় এবং প্রয়োজন হলে সেটি বারবার ব্যবহার করা যায়।

সহজভাবে বললে, Function হলো এমন একটি code block যা একটি নির্দিষ্ট কাজ সম্পন্ন করে।

  • Function তৈরি করার নিয়ম
  • Function call করা
  • Parameter এবং Argument

1. JavaScript Function কী?

Function হলো reusable code block। অর্থাৎ একটি কাজের জন্য code লিখে সেটিকে একটি নাম দেওয়া যায়। পরে সেই নাম ব্যবহার করে function চালানো যায়। 

function sayHello() {
```

console.log("Hello Munna!");
}
```

2. Function কেন ব্যবহার করা হয়?

একই code বারবার লেখার পরিবর্তে function ব্যবহার করলে code ছোট, পরিষ্কার এবং সহজে পরিচালনা করা যায়।

উদাহরণ:

function welcome() {
```

console.log("Welcome to Munna Tech");
}
```

এখন প্রয়োজন অনুযায়ী welcome() লিখে function চালানো যাবে।

3. Function তৈরি করার Syntax

function functionName() {
```

// code এখানে থাকবে

}
```

এখানে function হলো keyword এবং functionName হলো function-এর নাম।

4. Function Call কী?

Function তৈরি করলেই সেটি নিজে থেকে সবসময় execute হয় না। Function চালানোর জন্য function call করতে হয়। 

function sayHello() {
```

console.log("Hello!");

}

sayHello();
```

এখানে sayHello() হলো function call।

5. Simple Function Example

function showMessage() {
```

console.log("JavaScript শিখছি");

}

showMessage();
```

6. Function-এর ভিতরে একাধিক Code

function studentInfo() {
```

let name = "Munna";
let age = 20;

console.log(name);
console.log(age);

}

studentInfo();
```

7. Parameter কী?

Function-এর parentheses-এর মধ্যে যে variable লেখা হয় তাকে Parameter বলা হয়। 

function greet(name) {
```

console.log("Hello " + name);

}
```

এখানে name হলো parameter।

8. Argument কী?

Function call করার সময় parameter-এর জন্য যে actual value পাঠানো হয় তাকে Argument বলা হয়। 

function greet(name) {
```

console.log("Hello " + name);

}

greet("Munna");
```

এখানে "Munna" হলো argument।

9. Multiple Parameters

একটি function-এ একাধিক parameter থাকতে পারে। 

function student(name, age) {
```

console.log("Name: " + name);
console.log("Age: " + age);

}

student("Munna", 20);
```

10. Function দিয়ে Calculation

function add(a, b) {
```

console.log(a + b);

}

add(10, 20);
```

Output হবে: 

30

11. Return Statement কী?

Function থেকে কোনো value বাইরে পাঠানোর জন্য return ব্যবহার করা হয়। 

function add(a, b) {
```

return a + b;

}

let result = add(10, 20);

console.log(result);
```

এখানে function-এর result result variable-এ রাখা হয়েছে।

12. Return কেন গুরুত্বপূর্ণ?

Return ব্যবহার করলে function-এর result অন্য জায়গায় ব্যবহার করা যায়। 

function multiply(a, b) {
```

return a * b;

}

let total = multiply(5, 4);

console.log(total);
```

Output: 

20

13. String Return করা

function getName() {
```

return "Munna";

}

let name = getName();

console.log(name);
```

14. Boolean Return করা

function isAdult(age) {
```

return age >= 18;

}

console.log(isAdult(20));
```

এখানে result হবে true।

15. Default Parameter

কোনো argument না পাঠালে default value ব্যবহার করার জন্য default parameter ব্যবহার করা যায়। 

function greet(name = "Guest") {
```

console.log("Hello " + name);

}

greet();

greet("Munna");
```

16. Function Expression

Function-কে একটি variable-এর মধ্যেও রাখা যায়। 

const greet = function() {
```

console.log("Hello Munna");

};

greet();
```

17. Arrow Function

Modern JavaScript-এ function লেখার একটি সংক্ষিপ্ত syntax হলো Arrow Function। 

const greet = () => {
```

console.log("Hello Munna");

};

greet();
```

18. Arrow Function with Parameter

const greet = (name) => {
```

console.log("Hello " + name);

};

greet("Munna");
```

19. Short Arrow Function

যদি function শুধু একটি expression return করে, তাহলে আরও ছোট করে লেখা যায়। 

const add = (a, b) => a + b;
```

console.log(add(10, 20));
```

20. Function এবং Variable

Function-এর parameter-এ variable-এর value পাঠানো যায়। 

const userName = "Munna";
```

function welcome(name) {

console.log("Welcome " + name);

}

welcome(userName);
```

26. Function Reuse করা

Function-এর সবচেয়ে বড় সুবিধাগুলোর একটি হলো একই function অনেকবার ব্যবহার করা যায়। 

function greet(name) {
```

console.log("Hello " + name);

}

greet("Munna");
greet("Rahim");
greet("Karim");
```

28. Common Mistakes

  • Function তৈরি করে call না করা
  • Function name ভুল লেখা
  • Parameter ও argument-এর ধারণা গুলিয়ে ফেলা
  • Return করতে ভুলে যাওয়া
  • Parentheses ভুলে যাওয়া
  • Curly bracket ভুল করা
  • HTML element-এর ID ভুল লেখা
Beginner Tip: প্রথমে simple function practice করুন। তারপর parameter, return এবং arrow function শিখুন। প্রতিটি concept নিজে code লিখে পরীক্ষা করলে দ্রুত বুঝতে পারবেন।

30. Quick Revision

  • Function → reusable code block
  • Function declaration → function name() { }
  • Function call → name()
  • Parameter → function-এর ভিতরের input variable
  • Argument → function call-এর সময় পাঠানো value
  • Return → function থেকে value ফেরত পাঠায়
  • Arrow Function → function লেখার modern short syntax

31. Frequently Asked Questions

JavaScript Function কী?

Function হলো reusable code block যা একটি নির্দিষ্ট কাজ সম্পন্ন করতে পারে।

Function call কী?

Function execute করার জন্য function-এর নামের পরে parentheses দিয়ে function call করা হয়।

Parameter এবং Argument-এর পার্থক্য কী?

Function তৈরির সময় যে variable নেওয়া হয় সেটি parameter। Function call করার সময় যে actual value দেওয়া হয় সেটি argument।

return কী করে?

return function থেকে একটি value caller-এর কাছে ফেরত পাঠায়।

Arrow Function কী?

Arrow Function হলো JavaScript-এ function লেখার একটি সংক্ষিপ্ত syntax।
