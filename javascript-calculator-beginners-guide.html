9. eval() সম্পর্কে গুরুত্বপূর্ণ কথা

Beginner calculator project-এ অনেকে eval() ব্যবহার করে দ্রুত calculation করে। 

eval("10 + 20");

এটি কাজ করলেও real-world application-এ arbitrary user input-এর ওপর eval() ব্যবহার করা নিরাপত্তার দিক থেকে এড়িয়ে চলা ভালো। তাই আমরা এখানে একটি simple controlled calculator logic ব্যবহার করব।

20. Common Mistakes

  • JavaScript function-এর নাম ভুল লেখা
  • HTML ID এবং JavaScript ID না মেলা
  • parseFloat() ব্যবহার না করা
  • Operator সংরক্ষণ না করা
  • Division by zero handle না করা
  • JavaScript file HTML-এর সাথে ঠিকভাবে যুক্ত না করা
Beginner Tip: Calculator একবারে পুরোপুরি মুখস্থ করার চেষ্টা করবেন না। প্রথমে button click, তারপর variable, function, condition এবং DOM আলাদা আলাদাভাবে practice করুন।

22. Quick Revision

  • + → যোগ
  • - → বিয়োগ
  • * → গুণ
  • / → ভাগ
  • parseFloat() → string থেকে number তৈরি করতে সাহায্য করে
  • getElementById() → HTML element খুঁজে নেয়
  • .value → input-এর value নেয় বা পরিবর্তন করে
  • Function → একই কাজ বারবার ব্যবহার করতে সাহায্য করে

23. Frequently Asked Questions

JavaScript দিয়ে Calculator বানানো যায়?

হ্যাঁ। HTML দিয়ে structure, CSS দিয়ে design এবং JavaScript দিয়ে calculation logic তৈরি করে calculator বানানো যায়।

Calculator project কেন practice করব?

Calculator project-এর মাধ্যমে variable, function, condition, event এবং DOM-এর মতো গুরুত্বপূর্ণ JavaScript concept practice করা যায়।

eval() ব্যবহার করা উচিত?

Simple learning demo-তে এটি দেখা যায়, কিন্তু arbitrary user input নিয়ে real-world application তৈরি করার সময় eval() এড়িয়ে চলা ভালো।

Calculator বানাতে HTML ও CSS কেন দরকার?

HTML calculator-এর structure তৈরি করে এবং CSS সেটিকে সুন্দর ও ব্যবহারযোগ্য interface দিতে সাহায্য করে। JavaScript calculation চালায়।
