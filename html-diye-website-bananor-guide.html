HTML Tutorial

HTML দিয়ে প্রথম Website কীভাবে বানাবেন?

একদম Beginner level থেকে HTML ব্যবহার করে নিজের প্রথম Website তৈরি করার সম্পূর্ণ সহজ বাংলা গাইড।

✍️ Munna Tech 📚 Web Development ⏱️ 10 মিনিট পড়তে সময় লাগবে

আপনি যদি Web Development শেখা শুরু করে থাকেন, তাহলে আপনার প্রথম লক্ষ্য হওয়া উচিত একটি simple webpage নিজে তৈরি করা।

এই tutorial-এ আমরা একদম শুরু থেকে দেখব কীভাবে একটি HTML file তৈরি করবেন, HTML code লিখবেন এবং browser-এ নিজের প্রথম Website দেখতে পারবেন।

HTML Website তৈরি করতে কী লাগবে?

একটি simple HTML Website তৈরি করতে খুব বেশি কিছু প্রয়োজন নেই।

  • একটি PC বা Computer
  • একটি Browser
  • একটি Code Editor
  • HTML-এর basic knowledge
  • কিছু Practice

Beginnerদের জন্য VS Code একটি জনপ্রিয় code editor।

1 একটি নতুন Folder তৈরি করুন

প্রথমে আপনার PC-তে একটি নতুন folder তৈরি করুন।

উদাহরণ: 

My First Website

2 VS Code দিয়ে Folder Open করুন

এখন VS Code open করুন। তারপর:

  1. File Explorer খুলুন
  2. আপনার folder নির্বাচন করুন
  3. VS Code-এ folderটি open করুন

3 index.html File তৈরি করুন

এখন VS Code-এর ভিতরে একটি নতুন file তৈরি করুন।

File name হবে: 

index.html

💡 Tip: File name-এর শেষে অবশ্যই .html থাকতে হবে।

4 HTML Basic Structure লিখুন

এবার নিচের codeটি index.html file-এ লিখুন। 

<!DOCTYPE html>

<html lang="bn">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
        content="width=device-width, initial-scale=1.0">

    <title>My First Website</title>

</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        আমি Web Development শিখছি।
    </p>

</body>

</html>

5 File Save করুন

Code লেখার পর Ctrl + S চাপুন।

এতে আপনার HTML file save হবে।

6 Browser-এ Website দেখুন

এখন আপনার index.html file-এর উপর double-click করুন।

আপনার default browser-এ webpage open হবে।

🎉 Congratulations! আপনি আপনার প্রথম HTML webpage তৈরি করেছেন।

Website-এ নিজের নাম যোগ করুন

এখন আমরা webpage-টিকে একটু personal করি। 

<h1>
    Hi, I am Munna
</h1>

<p>
    I am learning Web Development.
</p>

<p>
    I want to become a professional
    Web Developer.
</p>

Website-এ Image যোগ করুন

HTML Website-এ image যোগ করতে <img> tag ব্যবহার করা হয়। 

<img
    src="profile.jpg"
    alt="Munna Profile Photo"
>

এখানে profile.jpg হলো image file-এর নাম।

Website-এ Link যোগ করুন

অন্য Website বা webpage-এ যাওয়ার জন্য link ব্যবহার করা হয়। 

<a href="https://example.com">

    Visit Website

</a>

একটি Complete Simple Website

এখন আমরা সবকিছু একসাথে ব্যবহার করে একটি simple personal webpage তৈরি করি। 

<!DOCTYPE html>

<html lang="bn">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
        content="width=device-width, initial-scale=1.0">

    <title>
        Munna's Website
    </title>

</head>

<body>


    <h1>
        Welcome to My Website
    </h1>


    <h2>
        About Me
    </h2>


    <p>
        My name is Munna.
    </p>


    <p>
        I am learning Web Development.
    </p>


    <h2>
        My Skills
    </h2>


    <ul>

        <li>
            HTML
        </li>

        <li>
            CSS
        </li>

        <li>
            JavaScript
        </li>

    </ul>


    <h2>
        My Goal
    </h2>


    <p>
        I want to become a
        professional Web Developer.
    </p>


    <a href="https://example.com">

        Visit Website

    </a>


</body>

</html>

HTML Website সুন্দর করার জন্য CSS কেন প্রয়োজন?

HTML দিয়ে Website-এর structure তৈরি করা যায়। কিন্তু Website-এর color, font, spacing, layout এবং design সুন্দর করতে CSS ব্যবহার করা হয়।

HTML = Structure
CSS = Design
JavaScript = Interaction

Beginnerদের জন্য Practice Project

HTML শেখার সময় নিচের ছোট projectগুলো তৈরি করতে পারেন:

  • Personal Profile Page
  • About Me Page
  • Simple Portfolio
  • Contact Page
  • Simple Blog Page
  • Personal CV Page

HTML শেখার পর কী করবেন?

HTML-এর basic ভালোভাবে শেখার পর CSS শেখা শুরু করুন।

এরপর JavaScript শিখলে আপনি আরও interactive এবং dynamic Website তৈরি করতে পারবেন।

Beginners-এর জন্য গুরুত্বপূর্ণ Tips

  1. প্রতিদিন code লিখুন।
  2. অন্যের code বুঝে practice করুন।
  3. ছোট project তৈরি করুন।
  4. HTML-এর tags মুখস্থ না করে ব্যবহার করে শিখুন।
  5. ভুল হলে ভয় পাবেন না।

Frequently Asked Questions

HTML দিয়ে কি Website বানানো যায়?

হ্যাঁ। HTML দিয়ে Website-এর basic structure তৈরি করা যায়। তবে professional design-এর জন্য সাধারণত CSS এবং functionality-এর জন্য JavaScript ব্যবহার করা হয়।

HTML শেখা কি কঠিন?

Beginnerদের জন্য HTML তুলনামূলকভাবে সহজ একটি starting point। নিয়মিত practice করলে basic webpage তৈরি করা সম্ভব।

HTML Website বানাতে কি Internet লাগে?

HTML code লেখা এবং browser-এ local file হিসেবে দেখার জন্য সবসময় Internet প্রয়োজন হয় না।

HTML-এর পরে কোন language শিখব?

সাধারণত HTML-এর পরে CSS এবং তারপর JavaScript শেখা হয়।

Conclusion

HTML দিয়ে প্রথম Website তৈরি করা Web Development শেখার একটি গুরুত্বপূর্ণ ধাপ।

শুরুতে Website খুব simple হলেও সমস্যা নেই। নিয়মিত practice করে ধীরে ধীরে CSS এবং JavaScript যোগ করলে আপনি আরও professional Website তৈরি করতে পারবেন।

আপনি যদি HTML-এর basic structure আরও ভালোভাবে শিখতে চান, তাহলে আমাদের আগের tutorial-টিও পড়তে পারেন।
