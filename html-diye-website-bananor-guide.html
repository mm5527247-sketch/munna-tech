🌐 HTML দিয়ে Website কীভাবে বানাবেন?

Beginnerদের জন্য HTML ব্যবহার করে নিজের প্রথম Website তৈরি করার সহজ Step-by-Step Guide

আপনি যদি নতুন করে Web Development শেখা শুরু করতে চান, তাহলে HTML হলো আপনার প্রথম গুরুত্বপূর্ণ ধাপ। HTML ব্যবহার করে একটি Website-এর মূল structure তৈরি করা হয়।

এই গাইডে আমরা একদম শুরু থেকে শিখব কীভাবে HTML দিয়ে একটি Simple Website তৈরি করা যায়।

📌 HTML কী?

HTML-এর পূর্ণরূপ হলো HyperText Markup Language। এটি Website-এর structure তৈরি করতে ব্যবহার করা হয়।

সহজভাবে বললে, একটি Website-এর Heading, Paragraph, Image, Link, Button এবং অন্যান্য content সাজানোর জন্য HTML ব্যবহার করা হয়।

🛠️ Website বানাতে কী কী লাগবে?

HTML Website তৈরি করার জন্য শুরুতে বেশি কিছু প্রয়োজন নেই।

  • 💻 একটি Computer বা Laptop
  • 🌐 একটি Web Browser
  • 📝 VS Code অথবা অন্য কোনো Code Editor
  • 📚 HTML-এর basic knowledge

📁 Step 1: একটি Folder তৈরি করুন

প্রথমে আপনার Computer-এর Desktop-এ একটি নতুন Folder তৈরি করুন।

Folderটির নাম দিতে পারেন: my-website

📄 Step 2: index.html File তৈরি করুন

এবার Folder-এর ভিতরে একটি নতুন file তৈরি করুন। Fileটির নাম হবে:

index.html

Website-এর homepage হিসেবে সাধারণত index.html ব্যবহার করা হয়।

💻 Step 3: প্রথম HTML Code লিখুন

এবার index.html fileটি VS Code-এ খুলে নিচের code লিখুন:

``` 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>My First Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first website.</p>

</body>

</html>
```

🔍 Step 4: Codeটি বুঝে নিন

<!DOCTYPE html>

এটি Browser-কে জানায় যে আমরা HTML5 document ব্যবহার করছি।

<html>

পুরো HTML document এই tag-এর ভিতরে থাকে।

<head>

Website-এর গুরুত্বপূর্ণ information যেমন title, meta information ইত্যাদি এখানে থাকে।

<title>

Browser tab-এ Website-এর যে নাম দেখা যায়, সেটি title tag-এর মাধ্যমে দেওয়া হয়।

<body>

Website-এ visitor যে content দেখতে পাবে, সেগুলো সাধারণত body-এর ভিতরে থাকে।

📝 Step 5: Heading যোগ করুন

Website-এর প্রধান heading তৈরি করতে h1 ব্যবহার করা হয়।

``` 
<h1>My Website</h1>
```

এছাড়াও h2, h3, h4, h5 এবং h6 heading ব্যবহার করা যায়।

📃 Step 6: Paragraph যোগ করুন

Paragraph লেখার জন্য p tag ব্যবহার করা হয়।

``` 
<p>I am learning Web Development.</p>
```

🔗 Step 7: Website-এ Link যোগ করুন

একটি Website থেকে অন্য Website বা অন্য page-এ যাওয়ার জন্য anchor tag ব্যবহার করা হয়।

``` 
<a href="https://www.google.com">
    Visit Google
</a>
```

🖼️ Step 8: Image যোগ করুন

Website-এ ছবি যোগ করতে img tag ব্যবহার করা হয়।

``` 
<img src="image.jpg" alt="My Image">
```

এখানে src দিয়ে image-এর location দেওয়া হয় এবং alt দিয়ে image-এর description দেওয়া হয়।

📋 Step 9: List তৈরি করুন

Website-এ বিভিন্ন item-এর list তৈরি করতে ul এবং li ব্যবহার করা যায়।

``` 
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

🌐 Step 10: Website Browser-এ দেখুন

Code লেখা শেষ হলে index.html file-এর উপর Double Click করুন।

আপনার Default Browser-এ Websiteটি খুলে যাবে।

💡 Tip: Code পরিবর্তন করার পর Browser-এ পরিবর্তন দেখতে Refresh করুন।

🎨 HTML-এর পর কী শিখবেন?

HTML দিয়ে Website-এর structure তৈরি করার পর আপনার পরবর্তী ধাপ হলো CSS শেখা।

  • HTML → Website Structure
  • CSS → Website Design
  • JavaScript → Website Interaction
