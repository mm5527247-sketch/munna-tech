HTML কী? Beginner-এর জন্য সহজ গাইড

HTML হলো web page তৈরি করার অন্যতম প্রধান technology। HTML ব্যবহার করে একটি webpage-এর structure তৈরি করা হয়।

HTML-এর পূর্ণরূপ কী?

HTML-এর পূর্ণরূপ হলো HyperText Markup Language।

HTML দিয়ে কী করা যায়?

HTML দিয়ে webpage-এ heading, paragraph, image, link, button, list এবং বিভিন্ন ধরনের content তৈরি করা যায়।

Heading কী?

HTML-এ h1 থেকে h6 পর্যন্ত heading ব্যবহার করা যায়। সবচেয়ে গুরুত্বপূর্ণ heading হলো h1।

Paragraph কী?

Text paragraph তৈরি করতে p tag ব্যবহার করা হয়। 



আমি HTML শিখছি।

Link তৈরি করা

একটি webpage থেকে অন্য webpage-এ যাওয়ার জন্য anchor tag ব্যবহার করা হয়।

HTML শেখার পর কী শিখবেন?

HTML শেখার পরে CSS শেখা ভালো। CSS দিয়ে webpage-এর design এবং appearance পরিবর্তন করা যায়। এরপর JavaScript শেখা যায়।

শেষ কথা

Web development শেখার প্রথম ধাপ হিসেবে HTML খুব গুরুত্বপূর্ণ। প্রতিদিন ছোট ছোট project তৈরি করে practice করলে শেখা সহজ হবে।
