HTML কী? Beginner Guide

আপনি যদি Web Development শেখা শুরু করতে চান, তাহলে HTML হলো শেখার অন্যতম প্রথম ধাপ। এই guide-এ খুব সহজভাবে HTML সম্পর্কে জানব।

HTML কী?

HTML-এর পূর্ণরূপ হলো HyperText Markup Language।

HTML ব্যবহার করে একটি website-এর বিভিন্ন content এবং structure তৈরি করা হয়।

HTML দিয়ে কী তৈরি করা যায়?

HTML দিয়ে website-এর heading, paragraph, image, link, button, list, table এবং বিভিন্ন section তৈরি করা যায়।

একটি Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>This is my first website.</p>

</body>

</html>

HTML Heading

HTML-এ heading তৈরি করতে h1 থেকে h6 পর্যন্ত tag ব্যবহার করা হয়। 

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Another Heading</h3>

HTML Paragraph

Paragraph লেখার জন্য p tag ব্যবহার করা হয়। 

<p>আমি HTML শিখছি।</p>

HTML Link

অন্য page বা website-এ যাওয়ার জন্য a tag ব্যবহার করা হয়। 

<a href="https://example.com">
    Visit Website
</a>

HTML Image

Website-এ image দেখানোর জন্য img tag ব্যবহার করা হয়। 

<img src="image.jpg" alt="My Image">

HTML List

List তৈরি করতে ordered list এবং unordered list ব্যবহার করা যায়। 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

HTML শেখার পর কী শিখবেন?

HTML-এর basic শেখার পর আপনার CSS শেখা উচিত। CSS দিয়ে website-এর design এবং appearance তৈরি করা হয়।

এরপর JavaScript শিখলে website-এ interactive features যোগ করতে পারবেন।

💡 Beginner Tip

শুধু code মুখস্থ না করে নিজে হাতে code লিখে practice করুন। প্রতিদিন ছোট ছোট website তৈরি করার চেষ্টা করুন।
