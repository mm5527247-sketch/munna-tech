JavaScript কী? Beginner-এর জন্য সহজ গাইড

JavaScript একটি programming language যা webpage-কে interactive এবং dynamic করতে ব্যবহার করা হয়।

JavaScript দিয়ে কী করা যায়?

JavaScript ব্যবহার করে button click-এর কাজ, form validation, calculation, interactive menu এবং অনেক ধরনের dynamic feature তৈরি করা যায়।

প্রথম JavaScript Code


console.log("Hello World");

এই code browser-এর Developer Tools-এর Console-এ message দেখাতে পারে।

Variable

Data সংরক্ষণ করার জন্য variable ব্যবহার করা হয়। 


let name = "Munna";

console.log(name);

Calculation


let a = 10;
let b = 5;

let result = a + b;

console.log(result);

if Statement


let age = 20;

if (age >= 18) {
    console.log("Adult");
}

Function

একই ধরনের কাজ বারবার করার প্রয়োজন হলে function ব্যবহার করা যায়। 


function greet() {
    console.log("Hello Munna Tech");
}

greet();

Button Click

DOM কী?

DOM-এর মাধ্যমে JavaScript HTML element-এর content এবং style পরিবর্তন করতে পারে।

JavaScript শেখার পর কী করবেন?

JavaScript basic শেখার পরে DOM, Events, Array, Object, Fetch API এবং ছোট ছোট project practice করা ভালো।

শেষ কথা

HTML দিয়ে structure, CSS দিয়ে design এবং JavaScript দিয়ে interaction তৈরি করা যায়। এই তিনটি technology web development-এর গুরুত্বপূর্ণ ভিত্তি।
