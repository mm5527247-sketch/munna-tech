WEB DEVELOPMENT

JavaScript কী? Beginner Guide

HTML website-এর structure তৈরি করে এবং CSS website-এর design করে। JavaScript ব্যবহার করে website-এ interaction এবং functionality যোগ করা যায়।

JavaScript কী?

JavaScript হলো একটি জনপ্রিয় programming language, যা web page-কে interactive এবং dynamic করতে ব্যবহার করা হয়।

JavaScript দিয়ে কী করা যায়?

JavaScript ব্যবহার করে button click, menu, form validation, calculator, image slider এবং আরও অনেক interactive feature তৈরি করা যায়।

JavaScript কীভাবে HTML-এর সাথে ব্যবহার করবেন?

HTML-এর ভিতরে script tag ব্যবহার করে JavaScript code লেখা যায়। 

<script>

    alert("Hello World!");

</script>

Variable

Data সংরক্ষণ করার জন্য JavaScript-এ variable ব্যবহার করা হয়। 

let name = "Munna";

console.log(name);

Numbers

JavaScript দিয়ে number নিয়ে calculation করা যায়। 

let a = 10;
let b = 20;

let result = a + b;

console.log(result);

Function

একই ধরনের কাজ বারবার করার প্রয়োজন হলে function ব্যবহার করা যায়। 

function greet() {

    console.log("Hello!");

}

greet();

Button Click

JavaScript ব্যবহার করে button click করলে কোনো action চালানো যায়। 

<button onclick="showMessage()">
    Click Me
</button>

<script>

function showMessage() {

    alert("Button clicked!");

}

</script>

Condition

কোনো condition সত্য বা মিথ্যা অনুযায়ী আলাদা কাজ করার জন্য if ব্যবহার করা হয়। 

let age = 20;

if (age >= 18) {

    console.log("Adult");

}

JavaScript শেখার সময় কী করবেন?

প্রথমে variable, data type, operator, condition, function এবং loop-এর মতো basic বিষয়গুলো ভালোভাবে practice করুন।

HTML + CSS + JavaScript

Web Development-এর মূল foundation হিসেবে HTML, CSS এবং JavaScript একসাথে শেখা খুব গুরুত্বপূর্ণ।

HTML দিয়ে structure, CSS দিয়ে design এবং JavaScript দিয়ে interaction তৈরি করা যায়।

💡 Beginner Tip

JavaScript শেখার সময় শুধু tutorial দেখবেন না। নিজে code লিখে ছোট ছোট project তৈরি করুন। যেমন Calculator, To-Do List বা Digital Clock।
