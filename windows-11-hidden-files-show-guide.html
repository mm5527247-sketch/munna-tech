Windows 11-এ Hidden Files Show করার নিয়ম | Beginner Guide

Windows computer ব্যবহার করার সময় কিছু files বা folders সাধারণভাবে File Explorer-এ দেখা যায় না। এগুলোকে Hidden Files বা Hidden Folders বলা হয়।

অনেক সময় troubleshooting, software configuration বা নিজের প্রয়োজনের কারণে এই hidden files দেখতে হতে পারে।

এই article-এ Windows 11 File Explorer ব্যবহার করে Hidden Files কীভাবে show এবং আবার hide করবেন তা সহজ বাংলায় দেখানো হয়েছে।

``` এই Article-এ আপনি শিখবেন:
  • Hidden Files কী?
  • Hidden Files কেন থাকে?
  • File Explorer দিয়ে Hidden Files show করার নিয়ম
  • Hidden Items option কোথায়?
  • Hidden Files আবার hide করার নিয়ম
  • Hidden এবং System Files-এর পার্থক্য
  • সতর্কতার বিষয়
  • Common problems ও FAQ
```

1. Hidden Files কী?

Hidden File হলো এমন file যেটি Windows-এর normal File Explorer view-তে সাধারণভাবে display না-ও হতে পারে।

একইভাবে কোনো folder-ও hidden attribute ব্যবহার করতে পারে।

2. Windows-এ Files Hide করা হয় কেন?

কিছু files সাধারণ user-এর regular কাজের জন্য প্রয়োজন হয় না। এগুলো accidental modification বা deletion থেকে দূরে রাখার জন্য hidden রাখা হতে পারে।

``` Important: Hidden মানেই file deleted বা damaged নয়। Fileটি computer-এ থাকতে পারে, কিন্তু normal view-তে display না-ও হতে পারে। ```

3. File Explorer খুলুন

Windows 11-এ Hidden Files show করার প্রথম ধাপ হলো File Explorer open করা।

Keyboard shortcut: 

Win + E

এই shortcut চাপলে File Explorer open হবে।

4. View Menu থেকে Hidden Items খুঁজুন

File Explorer open করার পরে উপরের View menu-তে যান। Windows 11-এর current interface-এ View menu-এর ভিতরে Show-এর মাধ্যমে Hidden Items option পাওয়া যেতে পারে।

```

Basic Path

File Explorer
  ↓
```

View
↓
Show
↓
Hidden items

5. Hidden Items Enable করুন

Hidden items option enable করলে hidden files এবং folders File Explorer-এ visible হতে পারে।

``` Step-by-step:
  1. Win + E চাপুন
  2. File Explorer খুলুন
  3. View menu নির্বাচন করুন
  4. Show option খুঁজুন
  5. Hidden items নির্বাচন করুন
```

6. Hidden File কীভাবে চিনবেন?

Hidden item visible হওয়ার পরে কিছু hidden file বা folder-এর icon/text normal item-এর তুলনায় হালকা বা faded appearance দেখাতে পারে।

তবে appearance-এর ওপর নির্ভর না করে file properties check করাই বেশি নির্ভরযোগ্য।

7. File Properties দিয়ে Hidden Attribute Check করুন

কোনো file বা folder hidden কিনা দেখতে সেটির Properties open করতে পারেন।

```
  1. File বা Folder-এর ওপর Right Click করুন
  2. Properties নির্বাচন করুন
  3. General tab দেখুন
  4. Attributes section খুঁজুন
```

সেখানে Hidden attribute enabled আছে কিনা দেখা যেতে পারে।

8. Hidden File আবার Hide করবেন কীভাবে?

কাজ শেষ হলে চাইলে Hidden Items option আবার disable করতে পারেন। 

File Explorer
      ↓
View
      ↓
Show
      ↓
Hidden items
      ↓
Disable

এতে hidden files আবার normal File Explorer view থেকে hidden হয়ে যেতে পারে।

9. Hidden File আর System File কি একই?

না। Hidden এবং System হলো আলাদা attributes।

```
Hidden File System File
Hidden attribute থাকতে পারে System-related attribute থাকতে পারে
Hidden Items option দিয়ে visible হতে পারে System files-এর জন্য আলাদা protection থাকতে পারে
সাধারণ file বা folder-ও hidden হতে পারে Operating system-এর গুরুত্বপূর্ণ file হতে পারে
```

10. Hidden Files দেখার সময় সতর্ক থাকুন

``` খুব গুরুত্বপূর্ণ: Hidden Files visible করার পর শুধু দেখা এবং প্রয়োজনীয় কাজ করা নিরাপদ। না বুঝে কোনো system-related hidden file delete, rename বা modify করবেন না। ```

বিশেষ করে Windows-এর গুরুত্বপূর্ণ system files নিয়ে experiment করা উচিত নয়।

11. Hidden Files Delete করা উচিত?

শুধু hidden হওয়ার কারণে কোনো file delete করা উচিত নয়।

আগে বুঝতে হবে fileটি কী এবং কেন আছে। প্রয়োজন না বুঝে delete করলে software বা Windows-এর কোনো feature সমস্যায় পড়তে পারে।

12. Hidden Files Show করার দরকার কখন হতে পারে?

    ```
  • কোনো software configuration file খুঁজতে
  • নিজের তৈরি hidden folder দেখতে
  • কোনো troubleshooting করতে
  • কোনো tutorial follow করার সময়
  • File management-এর প্রয়োজন হলে
    • ```

13. Hidden Items Option কাজ না করলে

যদি Hidden Items enable করার পরও কোনো নির্দিষ্ট file দেখা না যায়, তাহলে fileটি অন্য কারণে hidden হতে পারে।

উদাহরণ হিসেবে system-protected files-এর ক্ষেত্রে Windows অতিরিক্ত protection ব্যবহার করতে পারে।

``` সতর্কতা: শুধু কোনো tutorial দেখে protected system files visible বা editable করার চেষ্টা করবেন না। আপনি fileটির কাজ না জানলে সেটি modify না করাই ভালো। ```

14. File Explorer Search ব্যবহার করুন

Hidden item visible করার পরে প্রয়োজনীয় file খুঁজতে File Explorer-এর search ব্যবহার করতে পারেন।

File name বা extension জানা থাকলে search আরও সহজ হতে পারে। 

File Explorer
      ↓
Search
      ↓
File name / keyword

15. Hidden Folder তৈরি করার Basic ধারণা

আপনি নিজের কোনো personal folder-কে Hidden attribute দিতে পারেন। তবে এটি strong security method নয়।

কোনো file শুধু hidden করে রাখলে অন্য user চাইলে Hidden Items enable করে সেটি দেখতে পারে।

``` Security Note: Hidden attribute privacy-এর basic convenience দিতে পারে, কিন্তু এটি password protection বা encryption-এর বিকল্প নয়। ```

16. Beginner Practice

``` Practice Task:
  1. Win + E চাপুন
  2. File Explorer খুলুন
  3. View → Show → Hidden items খুঁজুন
  4. Hidden items enable করুন
  5. File Explorer-এর appearance লক্ষ্য করুন
  6. কাজ শেষে Hidden items আবার disable করুন
```
