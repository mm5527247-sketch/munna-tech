HTML কী? Beginnerদের জন্য HTML শেখার সম্পূর্ণ গাইড

HTML কী?

HTML-এর পূর্ণরূপ হলো HyperText Markup Language।

সহজভাবে বললে, HTML হলো একটি Markup Language যার মাধ্যমে একটি Website-এর বিভিন্ন অংশের structure তৈরি করা হয়।

যেমন একটি webpage-এ থাকতে পারে:

  • Heading
  • Paragraph
  • Image
  • Link
  • Button
  • List
  • Form
  • Table

💡 মনে রাখবেন: HTML একটি programming language নয়; এটি একটি markup language।

HTML কীভাবে কাজ করে?

একটি সাধারণ HTML file তৈরি করতে .html extension ব্যবহার করা হয়।

উদাহরণ:

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first webpage.</p>

</body>

</html>

এই code browser-এ open করলে browser HTML code বুঝে সেটিকে একটি webpage হিসেবে দেখাবে।

HTML Tag কী?

HTML-এ বিভিন্ন কাজের জন্য Tag ব্যবহার করা হয়। 

<h1>My Website</h1>

এখানে:

  • <h1> হলো opening tag
  • My Website হলো content
  • </h1> হলো closing tag

HTML-এর গুরুত্বপূর্ণ কিছু Tag

1. Heading Tag

Heading তৈরি করতে <h1> থেকে <h6> পর্যন্ত ব্যবহার করা যায়। 

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Small Heading</h3>

2. Paragraph Tag

Paragraph লেখার জন্য <p> ব্যবহার করা হয়। 

<p>আমি Web Development শিখছি।</p>

3. Link Tag

একটি webpage থেকে অন্য webpage-এ যাওয়ার জন্য <a> tag ব্যবহার করা হয়। 

<a href="https://example.com">
    Visit Website
</a>

4. Image Tag

Webpage-এ image যোগ করতে <img> ব্যবহার করা হয়। 

<img src="image.jpg" alt="My Image">

alt attribute image সম্পর্কে search engine এবং accessibility tools-কে তথ্য দিতে সাহায্য করে।

5. List Tag

HTML-এ list তৈরি করতে <ul>, <ol> এবং <li> ব্যবহার করা হয়।

Unordered List:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ordered List:

<ol>
    <li>HTML শিখুন</li>
    <li>CSS শিখুন</li>
    <li>JavaScript শিখুন</li>
</ol>

HTML Attribute কী?

HTML Tag-এর অতিরিক্ত information দেওয়ার জন্য Attribute ব্যবহার করা হয়। 

<a href="https://example.com">
    Visit
</a>

এখানে href হলো একটি attribute। 

<img src="photo.jpg" alt="Profile Photo">

এখানে src এবং alt হলো attribute।

HTML দিয়ে একটি Simple Website তৈরি

এখন আমরা একটি ছোট webpage তৈরি করি। 

<!DOCTYPE html>

<html lang="bn">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
        content="width=device-width, initial-scale=1.0">

    <title>My First Website</title>

</head>

<body>

    <h1>Welcome to My Website</h1>

    <h2>About Me</h2>

    <p>
        আমি Web Development শিখছি।
    </p>

    <h2>My Skills</h2>

    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
    </ul>

    <a href="https://example.com">
        Visit Website
    </a>

</body>

</html>

HTML শেখার জন্য কী কী দরকার?

HTML শেখার জন্য খুব বেশি কিছু প্রয়োজন নেই।

  1. একটি Computer বা PC
  2. একটি Web Browser
  3. একটি Code Editor
  4. নিয়মিত Practice

Beginnerদের জন্য Visual Studio Code (VS Code) ব্যবহার করা সুবিধাজনক।

HTML শেখার পর কী শিখবেন?

HTML শেখার পর সাধারণত CSS এবং JavaScript শেখা হয়।

  • HTML: Website-এর structure তৈরি করে।
  • CSS: Website-এর design এবং appearance পরিবর্তন করে।
  • JavaScript: Website-এ interaction এবং dynamic behavior যোগ করে।

সহজভাবে:

HTML → Structure
CSS → Design
JavaScript → Interaction
